## 0. Ruling

**PASS.** `LiveMt5Registration` is a **manager-session factory**, not a trader census. It builds exactly two `NativeMt5BrokerConnector` instances (Achiever + StarwaveFX), each with **one** Manager API `Login` used only as the `Connect` identity. It does not call `UserLogins`, `UserRequestArray`, `UserGetByGroup`, `GetAccountsAsync`, or any other user-list API. It applies **no** group mask, **no** `MT5_DEFAULT_GROUP` filter, **no** login allow-list, **no** `Take`/`Limit`.

`BrokerCodes` contains only `ACHIEVER` and `STARWAVEFX`. Catalog seed has the same two rows. This factory therefore registers **every** live source-MT5 broker the product defines. Downstream ALL-traders fetch is `GetAccountsAsync(null)` → `GetAccountsCore` walks **every** group, then `UserRequestArray` / `UserGetByGroup` / `UserLogins`+`UserRequestByLogins`. That enumeration lives in `NativeMt5BrokerConnector`, not here.

## No-loss implication

This file **only** constructs `NativeMt5Options` and two connector objects. It does not `Connect`, `DealRequest`, `DealAdd`, `OrderAdd`, `DealerBalance`, or emit FIX `NewOrderSingle`. Password and proxy-auth fields are copied into options; this slice does **not** print those values.

A wiring miss (`Login = 0`, empty `Server`, both-password AND-gate) fails **before** a Manager session that can mutate books. `LiveIngestHostedService` catches per-broker connect/catalog exceptions and logs “No dummy data will be substituted.” Incomplete census after a **failed** connect is no-loss: no pump, no dealer, no order.

Once a connector constructed here **does** connect, capital-risk APIs live on `CIMTManagerAPI` inside `NativeMt5BrokerConnector` — later slots. Product DI still sets `RealCopyEnabled = false` independently of this factory.

**Honest limit:** this file cannot *prove* a live Achiever/StarwaveFX session actually returned every server login. Manager group rights, pump mode, and `ReadAccountsForGroup` completeness are out of this file. Slot 152 only proves registration does not itself truncate the ALL-traders fetch.
