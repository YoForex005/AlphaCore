## Verdict

**FAIL — no. This file does not implement a martingale filter, and its averaging flag is not strong enough to cut the left tail.**

What the file actually does:

- **Averaging = a same-`PositionId` latch.** On same-side `DealEntry.In`, `ScaleIn` compares fill price to **pre-fill** entry VWAP (`LONG: price < VWAP`, `SHORT: price > VWAP`). One worse add sets `WasAveragedDown = true` forever. That is A21 polarity. It is **detection**, not a filter.
- **Martingale = absent.** Sequential size-up after a **closed** loss is computed later in `BaselineScorer` from `MaxVolumeLots` across **completed** XAU rows. This class never sets a martingale bit and never drops a size-up lifecycle.
- **First-3 is a counter.** `IsEarlyScoreEligible` is `CountCompletedXauUsdTrades >= 3`. Averaged / scaled / no-SL books still count. Cancel-dirty only flips `EligibleForFirstThree`; production scoring **does not read that bit**.
- **Hedging grids are invisible.** A21 §1.6 / §8.1: each hedge `position_id` is its own lifecycle; do **not** merge. Classic XAU martingale/grid on MT5 hedge accounts opens **new** tickets. None of those INs hit `ScaleIn`. `WasAveragedDown` stays false on every leg. That is the actual left-tail shape of challenge books.
- **Downstream leak is structural.** Scorer `AveragingDown = trades.Any(t => t.WasAveragedDown)` adds **+20** risk. `RISK_BLOCKED` needs `risk >= 80` **or** `(Martingale ∧ DD > 0 ∧ NetPnl < 0)`. Averaging alone never blocks. A **winning** 1.26× martingale is `risk = 35` and can land **`SHADOW`**. `RiskEngine` has `BlockMartingale` and **no** averaging field. `CopyTradingService` passes `MartingaleFlag = score.Martingale` and never `WasAveragedDown`.

Live census does not rescue the flags:

- 8463 source accounts can still run grids on the challenge side. This class reconstructs them as many small clean trades.
- Achiever scoring exists; Starwave **deals-done scored 0** means that broker’s left tail is **unscored**, therefore unfiltered.
- SHADOW all demo + `destinationRealPnl` 0 + `REAL_COPY` false means dest left tail is cut by **not copying**, not by reconstructor filters.
- FIX **LoggedOn** is session state. Logon without a behavior gate is not a left-tail cut.

Empty PASS is **forbidden** here: the file was read in full and is not empty. The honest measured answer on the assigned angle is **FAIL**.

## Profit implication

**None from these filters.** `TradeReconstructor` cannot create destination edge. It rebuilds source lifecycles and, for netting same-ticket adds, paints `WasAveragedDown`.

If copy is later enabled on “high quality + SHADOW” books:

- Hedge-mode grids look like many small independent winners. `WasAveragedDown` stays **false**. Mild sequential 1.26× after a closed loss is martingale in the scorer (`risk = 35`) and can still be **`SHADOW`** (`quality >= 70 && risk < 40`). Averaging-only is `risk = 20`. Those are exactly the still-green left-tail books that print the **right** tail of source P&L first.
- Architecture / docs copy story is “winning trades.” That **selects** the right tail. The left tail arrives on the same pattern after dest size is on.
- Measured now: `destinationRealPnl` **0**, `REAL_COPY` **false**, SHADOW all demo. Starwave deals-done scored **0** — no scored profit signal from that broker. Achiever scoring of 8463 accounts is source observation, not dest EV.
- Turning `REAL_COPY` on while treating this class as a tail screen would **replicate** challenge-side grids onto Pepperstone, not harvest a measured dest edge.

Do not treat `IsEarlyScoreEligible == true` or a high early score after three completed XAU as profit.

## Lower-loss implication

**Dest capital is currently parked by `REAL_COPY` false / `CanPromoteToLive => false` / copy `AllowFixSend = false` / `SHADOW_ONLY`, not by this file’s flags.**

What would actually cut source-pattern left tail, and is **missing** here:

1. A martingale bit on the reconstructed trade (or a basket detector across hedge `position_id`s in a time window / symbol). A21 forbids merging tickets into one scale-in, so the detector must live **above** this class — and it does not exist on this leaf.
2. Hard exclude of `WasAveragedDown` (and basket-grid) from first-3 / SHADOW eligibility. Today first-3 **counts** them; production score **ignores** `EligibleForFirstThree`.
3. Averaging as a dest risk reject (`BlockAveraging` on `RiskEvaluationRequest`). Absent.
4. Block winning martingales, not only `NetPnl < 0`. Stub does not.
5. Starwave scored 0 ⇒ **zero** filter coverage on that broker’s tail. Unscored is unfiltered.

If scoring/copy is enabled without those, the reconstructor latch misses the dominant XAU blow-up (many hedge tickets, size-up after closed losses) and the scorer only hard-blocks the already-red martingale. That is **not** a lower-loss control. It is a label on a minority netting path.

FIX LoggedOn without a behavior gate does not reduce dest loss. `destinationRealPnl` staying 0 is the only measured dest-loss cut today.
