## Profit implication

**None from this file’s filters — they do not exist.**

The doc’s copy rule is “winning trades are copied.” That **selects the right tail of source realized P&L**, which is exactly how a still-green martingale / average-down book gets onto the dest book. On gold, the profitable phase of a grid *is* the right tail; dest profit during that phase is not edge, it is uncompensated left-tail premium.

If someone later treated this document as sufficient screening and flipped `REAL_COPY`:

- Averaging-only SHADOW books (classic one-ticket XAU add-lower, `risk=20`) would be in the copyable set and **invisible** to `RiskEngine`.
- Winning sequential martingales (`risk=35`, C32 SHADOW) would be in the copyable set; dest increasing actions would then depend on the **caller** passing `MartingaleFlag` — a gate that is **not specified** on this leaf.
- Starwave deals-done scored **0** means there is **no** scored profit signal from that broker to copy; enabling send from an unscored 0-tape is not profit, it is unfiltered replication.

Measured dest profit today is **0** (`destinationRealPnl` 0, `REAL_COPY` false, SHADOW all demo). This leaf cannot create dest edge.
