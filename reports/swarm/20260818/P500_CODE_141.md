## Verdict

**YES — a copy-every-scored-XAU policy is expected to lose money if it were live.**

`RiskEngine.Evaluate` never sees `TraderState`. The request has no field for `RISK_BLOCKED` / `SHADOW` / `LIVE` / `CompletedXauTrades`. `BrokerId` and `SourceLogin` are required and **never read**. Spec token `TRADER_RISK_BLOCKED` (A23 / A71 G20) is **never emitted**. This file cannot refuse a name because scoring already labeled it a martingale loser or `risk >= 80`.

Martingale is blocked **only if the caller sets `MartingaleFlag=true`**. Abnormal size is the same pattern (`AbnormalSizing`). Caps (`MaxXauGross=20`, `MaxXauNet=10`, `MaxOpenPositions=20`, `MaxPositionQuantity=5`) are last-ditch size brakes on **caller-supplied** snapshots, not a quality screen. `MAX_XAU_NET` is labeled `ReduceSize` but goes through `Reject()` → `ApprovedQuantity=0`. `MaxSlippage=1.5` is declared and **never read**. Loss / daily-loss / portfolio-DD checks apply to **every** action, so a red dest day **cannot exit** through this method.

**Current dest is not losing.** `AllowFixSend` requires `RealExecutionEnabled` (caller pin `REAL_COPY false`). The empty `if` on lines 90–93 does not reject — it still `APPROVE`s. Unit `Real_flag_false_never_allows_fix_send` asserts `Outcome=Approve` and `AllowFixSend=false`. Product persist (`CopyTradingService`) hard-writes `AllowFixSend=false`, keeps `VenueReconciled=false` / `NewOrderSingleImplemented=false`, and only *intents* `SHADOW` / `LIVE_CANDIDATE` / `LIVE` — **not** `RISK_BLOCKED`. SHADOW is all demo. `destinationRealPnl` is constructor literal **0**. FIX LoggedOn is session, not send. Starwave scored **0**.

Do **not** flip `REAL_COPY` and spray every Achiever score onto one Pepperstone gold book. That is the losing path this file fails to stop by state.

## Profit implication

**Copy-every-scored-XAU is not a profit path.** The class scoring **blocks** is defined as losing martingale (or risk ≥ 80). Live measured: that bucket is **−$241,580** vs SHADOW **+$78,276** and WATCH **+$8,178**. The blocked tail is larger than the SHADOW head. All-scored source EV is **−$154,425**. Dest costs (Pepperstone spread/commission, 15 s `MaxSourceSignalAge`, gold scalps, demo challenge adverse selection) make copy-all **worse**, not better.

If that policy were live and this engine were the only gate:

1. Dest aligns to **one** metal (no Phase-2 concentration cap here).
2. `RISK_BLOCKED` names are treated as if they were `SHADOW` quality unless `MartingaleFlag` is set.
3. Size-up-after-loss copies whenever the caller forgets the flag (or a `risk>=80` name is not martingale-flagged).
4. Hits 10 net / 20 gross lots of the **same** metal, then hard-zero further adds — leftover dest stays long/short the losing cluster.
5. On the first −500 / −2_000 / 3_000 dest day, **refuses to close**.
6. `MaxAllowedSpread=2.0` on gold is ~$200/lot if the unit is dollars — too loose to save a spray.
7. Dead `MaxSlippage` cannot reject a dest fill that already slipped past 1.5.

Starwave deals-done scored **0** adds **no** XAU edge. 8463 catalog rows are **not** 8463 copy candidates. Achiever scoring is observation. FIX LoggedOn does not monetize scores. With `REAL_COPY false` and `destinationRealPnl` **0**, there is **no** live dest profit and **no** live dest loss from this file.

Higher dest profit is **not** “copy more scored logins.” It is **not copying** the left tail, then proving a tiny filtered SHADOW book after real quotes.
