## Verdict

**NO — WOULD_NOT_SURVIVE.**

What this compilation unit actually does:

1. TCP connect + TLS 1.2/1.3 to the supplied host/port, **20 s** linked cancel (`CancelAfter`).
2. Build and write **one** FIX.4.4 Logon (`35=A`, `108=30`, `141=Y`).
3. **One** `ReadAsync` (4 KiB). If inbound `35=A`, return `LoggedOn=true`, `Status="LoggedOn"`.
4. Dispose `TcpClient` / `SslStream` on every exit (`using` / `await using`). There is no keep-alive loop.

What it does **not** do (all measured 0 in this file):

| Persistent TRADE socket after logon | **No** — disposed before return |
| Heartbeat `35=0` matching advertised `108=30` | **No** |
| Market-data subscribe / bid-ask cache | **No** |
| Spread read (`Ask - Bid`) | **No** |
| `NewOrderSingle` / `35=D` / tags 11/38/40/54/55 | **0** |
| ExecutionReport / fill time | **No** |
| Source-to-fill / FIX RTT histogram | **No** |
| Re-check of `MaxSourceSignalAge` / `MaxQuoteAge` at send | **No** |

A 3-minute gold scalp can survive a **hot** FIX hop (tens–hundreds of ms) plus a **tight** XAU spread only if the TRADE/QUOTE sockets stay up and quotes are fresh. This type gives the opposite: a **cold** logon that can legally sit on the 20 s timeout (11 % of the hold, **10×** the 2 s copy-delay ceiling in `docs/risk.md`, and able to blow the 15 s `MaxSourceSignalAge` in `RiskEngine`). Advertised HeartBtInt **30 s** is **1/6 of the hold** and is never serviced. Destination spread is not observed here at all.

FIX **LoggedOn** in live runtime is a **probe result**, not a live order path. `CTraderFixLogonHostedService` pins `_runtime.RealCopyEnabled = false` after the same `TryLogonAsync`. `apps/fix-worker/Worker.cs` then stamps both session rows `Disconnected` / “No live TRADE socket.”

Empty PASS is **refused**. The file was read; the angle fails.

## Lower-loss implication

**Current loss floor is “do not send,” not “survive latency+spread.”**

- `SAFE_BY_ABSENCE`: no encoder, one `WriteAsync` of Logon, sockets gone, `RealCopyEnabled` forced **false**. This process cannot open a losing live XAU position through this type. That is why dest real P&amp;L is 0 and SHADOW is all demo.
- That is **not** a tested refuse of a stale 180 s scalp on a live TRADE socket. `CopyIntentExpiry` only checks `now - sourceEventTime > maxSignalAge` and is not invoked here. `RiskEngine.Evaluate` is unwired from this session.
- **Worse case if send were added on top of this probe:** re-TLS + 20 s cancel + no heartbeat + no quote ⇒ dest fill after source close ⇒ **orphan dest exposure** (missed scalp **and** leftover risk). Heartbeat 30 s cannot detect a dead TRADE inside the hold. Cert callback `(_, _, _, _) => true` is not a PnL hedge.
- Lower-loss vs live copy therefore remains: **keep `REAL_COPY` false; do not add `35=D` to this dispose-after-logon type; do not copy gold holds &lt;3 min until a hot session, measured source-to-fill, and a tight measured spread gate exist.**
