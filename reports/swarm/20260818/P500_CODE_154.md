Architecture v2 **requires** two independent money tiles and binds only the first to dest prints:

1. **Shadow P&L** (§24 / §31 / §47 / §69.11 / Phase 5) — dest-venue *simulation* priced from the **cTrader QUOTE FIX** session (bid/ask, freshness, slippage, delay). Must persist `shadow_pnl` / `shadow_performance`, not source ticks.
