## Why 95.5 is not dest PnL (implemented arithmetic)

`BaselineScorer.EarlyScoreTradeCount = 3`. `Score()` builds `EarlyQualityScore` from **source** `NetRealizedPnl` / profit factor / behavior / risk. It never reads a destination fill, quote, or copy intent.

```text
quality = 50
+15 if NetPnl > 0
+10 if ProfitFactor >= 1.2
+5  if ProfitFactor >= 1.8
+ behavior * 0.2
- risk * 0.25
if n < 3: quality = min(quality, 40)
clamp/round2 → EarlyQualityScore
```

**95.50 identity** (demo seed, B12 / D37 / E007 measured): no SL on the deal DTO → `risk += 10` (`SlUseRate < 0.3`), `behavior -= 10` (`SlUseRate < 0.5`) → risk **10**, behavior **90**. Clean profitable book:

`50 + 15 (NET>0) + 10 (PF≥1.2) + 5 (PF≥1.8) + 90×0.2 − 10×0.25 = 95.50`.

Every term is **source tape**. Destination realized is not an input.

State ceiling for that 95.50 (`TraderStateMachine.FromBaseline`):

```text
quality >= 70 && risk < 40 → SHADOW
AfterHighEarlyScore()      → SHADOW
CanPromoteToLive(_)        → false
```

95.50 ≥ 70 and risk 10 < 40 → **`SHADOW`**. Promotion to LIVE is hard-false.
