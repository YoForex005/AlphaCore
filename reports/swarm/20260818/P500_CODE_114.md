## Angle

Does architecture v2 make shadow P&L a book marked on **real Pepperstone/cServer QUOTE** prints, or is destination real P&L still **zero** (no dest fills, no dest-quote book)?

The two halves are independent:

1. **Shadow P&L (required):** dest-venue simulation priced from the cTrader QUOTE session.
2. **Destination real P&L (tile):** realized + conservative unrealized on the **actual** TRADE book after fills.

Live `REAL_COPY=false` plus no `35=D` makes (2) **must stay 0**. That does **not** prove (1) is live.

## Verdict

**`destinationRealPnl` is still zero. Shadow P&L is not using real cTrader quotes.**

After reading architecture v2 in full:

- §24 + §31 **bind** shadow pricing to the cTrader QUOTE FIX session (bid/ask, freshness, slippage).
- §17 **forbids** pretending a cTrader print is the source MT5 tape.
- §41 **allows** QUOTE+TRADE logon with `REAL_COPY_EXECUTION_ENABLED=false` so prices can flow **without** NewOrderSingle.
- §47 **separates** the two overview tiles: `Shadow P&L` vs `Destination real P&L`.
- §23 / §32 / §41: dest real P&L can only exist after approved `35=D` fills. Default flag is **false**.

Product (adjacent, to test the architecture claim — not a substitute for reading the assigned file):

- `EfDashboardQueries.GetOverviewAsync` writes `DestinationRealPnl` as the literal **`0`**. `ShadowPnl` is `SUM(shadow_orders.SourceVsShadowSlippage)`, not §24 `shadow_pnl` / `shadow_performance` MTM.
- Trader-row `ShadowPnl` is a second literal **`0`**.
- The only `DestinationQuotes.Add` is `DemoSeeder` (`Bid=2399.45`, `Ask=2399.85`, `VenueInstrumentId=null`).
- `CTraderFixLogonHostedService` persists **session rows** after `35=A`. It never writes `destination_quotes`, never sends `35=V` / `35=y`.
- `CTraderFixSession.TryLogonAsync` sends MsgType **A** only, then returns. No MarketDataIncrementalRefresh persist.
- `ShadowCopyEngine.MarkToMarket` has **one** definition and **zero** callers.
- `CopyTradingService` / `PersistDemoShadowAsync` will *use* whatever row is in `destination_quotes` if present. That row is the **demo seed**, not a live QUOTE snapshot.

Honesty: dest PnL **0** is the **correct** capital statement while `REAL_COPY` is false. Calling the overview Shadow tile “cTrader-quote PnL” would be greenwash.

- Starwave scored 0 contributes **nothing** to a dest-quote shadow book. There is no hidden Starwave dest profit.

## Lower-loss implication

**Capital-protective by non-participation, not by dest-aware shadow.**

- `REAL_COPY=false` + no `35=D` + dest PnL hard-zero ⇒ this process **cannot** lose Pepperstone money today. Lower-loss is “do not send,” not “size down on dest quotes.”
- Architecture §23 / §41 is a **loss floor**: trade #3 stays SHADOW; NewOrderSingle requires an explicit flag plus a healthy risk engine.
- Architecture §62 (QUOTE unavailable → no new priced live copy) is the lower-loss rule the product should honor. LoggedOn-without-quotes should **fail closed** for any later send. It currently fails closed only because the sender is unimplemented (`SAFE_BY_ABSENCE`).
- Residual operator risk (not capital today): reading a non-zero Shadow tile as “we already measured dest-quote edge” and flipping `REAL_COPY` later. That would copy against an **unmeasured** dest book and can **increase** dest losses.
- Fake 2399 seed as a go-live slippage gate would accept/reject the wrong names (seed spread 0.40 vs live XAU). That is a future loss amplifier, not a current debit.

Lower-loss vs live copy remains “do not send.” Dest-quote shadow is the **measurement** that would later let you refuse bad copies. That measurement is not running.

## What would flip this to “shadow uses real cTrader quotes”

1. QUOTE session stays LoggedOn **and** sends SecurityList + MarketDataRequest (`35=y` / `35=V`).

4. Overview `ShadowPnl` sums dest-marked `shadow_pnl` / `shadow_performance`, not `SourceVsShadowSlippage` alone.
5. `DestinationRealPnl` stays **0** until `REAL_COPY` + fills exist (that half should **not** flip just because quotes are live).
