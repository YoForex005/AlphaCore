## Verdict

**FAIL — NO. Gold scalp holds under 3 minutes would not survive FIX latency plus dest spread on this path.**

`CTraderFixSession` is a **one-shot TLS Logon probe**, not a trade or quote session. `TryLogonAsync` opens `TcpClient` + `SslStream`, writes one FIX 4.4 `35=A`, reads **one** 4096-byte chunk, returns `LoggedOn=true` if inbound tag 35 is `A`, then **`using` disposes the socket**. The compilation unit never:

- keeps a session alive for 180 s
- runs the advertised `HeartBtInt=30` loop (tag `108=30` is written, never scheduled; no `35=0`, no TestRequest)
- subscribes to XAUUSD market data (`35=V` lives only in unused `CTraderQuoteService`)
- measures bid, ask, or spread
- sends `NewOrderSingle` (`35=D` count = **0**; `NewOrderSingle` count = **0**)
- receives an ExecutionReport (`35=8`)
- stamps `fix_send_time` / `execution_time` (architecture §36 hops are absent)
- times source-to-fill

A sub-3-minute gold scalp needs dest entry, dest exit, and remaining hold after copy delay that still covers **2× dest half-spread + dest lag slippage**. This file provides none of those.

A **hot** Equinix FIX RTT (tens–low-hundreds of ms) plus a **tight** measured XAU spread *could* be compatible with some 180 s holds. **This type is not that path.** It is a **cold** connect that can legally consume the entire 20 s cancel budget before any dest order exists.

|---|---|
| 20 s `CancelAfter` on connect+TLS+logon+one-read | **11%** of the hold **before any dest order exists**; **10×** the 2 s copy-delay ceiling in `docs/risk.md`; can blow the 15 s `MaxSourceSignalAge` before send |

| `MaxAllowedSpread = 2.0` XAU points | Can consume an entire typical scalp target **before** lag |
| Shadow dest-touch; +`0.05` pts when `modeledDelay > 250 ms` | Long pays dest ask, short pays dest bid. Product shadow currently models **80 ms** (no overlay). Any real hop >250 ms adds 0.05 on top of full spread |
