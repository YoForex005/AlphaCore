## Verdict

**FAIL — no. This file has zero martingale/averaging filters, so they cannot cut the left tail.**

The assigned document is a hedge-venue protocol note. It tells the operator how to discover instruments, subscribe quotes, copy a fill, reconcile slippage, and avoid double-submit after a lost ExecutionReport. It does **not** screen *which* source books are allowed to become dest size.

The copy sentence that *is* in the file is the opposite of a left-tail filter: **“winning trades are copied.”** That selects the **right** tail of realized source P&L. A still-green martingale or average-down book is exactly the book that looks copyable first; the left tail arrives later on the same pattern.

Adjacent law (not this file; quoted so the FAIL is not a docs-only nit):

- `docs/scoring.md` *claims* “Martingale / large sequential size-up after losses ⇒ `RISK_BLOCKED`.” That sentence does **not** appear in `ctrader-fix.md` and is **not** wired onto the FIX path this doc describes.
- `BaselineScorer` detector: martingale = **adjacent** completed XAU pair with prior `NetRealizedPnl < 0` and next `MaxVolumeLots > 1.25×` (strict `>`). Averaging = `trades.Any(t => t.WasAveragedDown)`. Risk additives **+35 / +20**. `RISK_BLOCKED` only if `risk >= 80` **or** `(Martingale ∧ MaxDrawdown > 0 ∧ NetPnl < 0)`.
- Winning-book algebra (no extra flags):
  - Martingale only → risk **35** → can land **`SHADOW`** (`quality >= 70 && risk < 40`).
  - Averaging only → risk **20** → **never** reaches 80.
  - Martingale + averaging → risk **55** → still **not** `RISK_BLOCKED` if `NetPnl >= 0`.
  - Martingale + averaging + lot-escalation → risk **70** → still under 80.
  - A winning grid needs **three extra hits stacked with both flags** (e.g. +CV +low-SL +DD>GP) before the hard state fires.
- Detector holes that leave left-tail size invisible: skip-one recovery (non-adjacent); exact `1.25×` after a loss (`0.125 > 0.125` is false); intra-position grid is averaging, not martingale; `N=0` snapshot forces both flags **false**; Starwave **deals-done scored 0** means that broker’s tape never enters the scorer.
- Unit lock is the **losing** 2×/2× book only (`Martingale_after_losses_is_risk_blocked`). There is no fact that a **winning** martingale is blocked.
- `RiskEngine`: `BlockMartingale` rejects *increasing* copy when the **caller** already set `MartingaleFlag`. **No** `BlockAveraging` / `AveragingDown` field exists on `RiskLimits` or `RiskEvaluationRequest`. Averaging is invisible to dest risk. `Evaluate` never sees `TraderState` / `RISK_BLOCKED`.
- `TradeReconstructor.ScaleIn` *detects* add-at-worse-price vs entry VWAP. Detection ≠ FIX reject.
- `CanPromoteToLive(_) => false` is a vacuous LIVE pin in the scorer, **not** a martingale/averaging tail cut, and it is not mentioned in this FIX doc.

Live census does not rescue the filters:

- **8463** source accounts can still run grids on the **challenge** side. This doc does not rank or block them.
- Achiever scoring exists; Starwave **deals-done scored 0** means that broker’s left tail is **unscored**, therefore unfiltered by the scorer.
- SHADOW all demo + `destinationRealPnl` **0** + `REAL_COPY` **false** means dest left tail is cut by **not copying**, not by martingale/averaging filters.
- FIX **LoggedOn** is session state (`LiveRuntimeStatus.FixLiveStatus.LoggedOn`). Logon without a behavior gate is not a left-tail cut.
