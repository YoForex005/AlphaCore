`TickRosterAsync` (L112–198) walks **all** `TraderScores`:

1. Rebuild `CopyTraderSnapshot` + completed XAU via `ToResult`.
2. `onRoster = row is not null && row.Status == "ADMITTED"` (L136). `REMOVED:*` is **off** the roster.

5. **RemoveAndFlatten** → `Status=REMOVED:{reason}`, `Action=CloseExposure`. If `FlattenDestination`, call `FlattenOpenCopiesAsync`.

Same-tick consumers **cannot** treat a just-removed login as a seat:

| Consumer | Gate | Effect if `REMOVED:*` |
|---|---|---|
| `GenerateShadowIntentsAsync` L231–232 | `roster.Status != "ADMITTED"` → `continue` | No new `copy:` opens; source-close hopper also skipped |
| `ExecuteDemoCopyAsync` L542–544 | `Status == "ADMITTED" && key starts with roster:` | No new dest `CTraderFixCopyOpen` for that login |

So a loser is **not left on the roster** as an open-risk seat after the tick that sees the breach.

`FlattenOpenCopiesAsync` (L416–449):

- Matches `OpenExposure` + `IdempotencyKey.StartsWith("copy:")` for that broker/login.
- Skips if `copy:{broker}:{login}:{pos}:close` already exists.
- Inserts dest `CloseExposure` / `Status=FLATTEN_LOSS_CUT` / 15 s expiry / qty = prior open `RequestedQuantity`.
- Does **not** call Manager. Does **not** close MT5 source. Does **not** call `CTraderFixCopyOpen`. Does **not** read `FLATTEN_LOSS_CUT` later.

`ExecuteDemoCopyAsync` dest-close loop is **source-complete + ledger fill**, not REMOVE. Residual: dest inventory opened before eject stays until the **source** ticket completes (or a human flatten). That is dest-orphan risk if a sender is live, **not** “loser still ADMITTED.”
