## What the file actually is

`LiveCopyPage` is the `/live` route component (`App.tsx` mounts it at `<Route path="live" element={<LiveCopyPage />} />`). It:

1. Calls `useCopyStatus()` and `useCopyIntents()` (React Query **GET** polls).
2. Renders a title, a summary string, eight status tiles, an optional blockers list, and a table of copy intents.
3. Has **zero** `<button>`, `<form>`, `onClick`, `onSubmit`, `fetch(`, `POST`, `PUT`, `PATCH`, `DELETE`, WebSocket send, FIX codec, or order-builder.

The page *displays* whether REAL_COPY is armed and whether TRADE/QUOTE sessions are up. Display is not send.
