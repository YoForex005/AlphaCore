## Profit implication

Hard-false **blocks** live profit. It does **not** protect it.

- 8463 catalog logins cannot become destination LIVE books through this pin. Scoring only walks logins that already have `Mt5Deals` rows.
- Achiever books that land `SHADOW` (quality ≥ 70 and risk &lt; 40) stay paper. Winner tape is not copied as real cTrader exposure. Opportunity cost is the entire destination book.
- Starwave **scored 0** after `deals-done`: that cohort is not in the scorer loop this pass. Zero chance of a live harvest from Starwave regardless of the pin.
- Dashboard dest real P&amp;L is **structurally 0**, independent of source-MT5 quality. Shadow P&amp;L is Σ `SourceVsShadowSlippage`, not destination realized.
- `VolumeConverter` cannot create profit: it only scales native volume → lots. Wrong scale would mis-detect martingale (`lots[i] > lots[i-1] * 1.25` after a loss) and would mis-size a future `RequestedQuantity`. Today there is no send, so that is a **latent** sizing risk, not a P&amp;L event.

If the question is “does hard-false keep us from giving back open profit?” — **no live book exists to protect.** Protecting profit would require a live position and a trail/halt. This pin prevents the position from existing.

## Lower-loss implication

Hard-false **does** lower live loss (capital protection), together with other off-switches — **not** because `VolumeConverter` refuses LIVE.

- N=3 early evidence cannot auto-promote. Architecture / `docs/scoring.md` require SHADOW max. The pin is **stricter than required** (false for every state / every N).
- Application never calls `CanPromoteToLive`. Persist will copy whatever `SuggestedState` is. Safety today is “LIVE is not in the reachable set,” not “a gate evaluated LIVE then denied.”
- `REAL_COPY=false` + `NewOrderSingleImplemented=false` + `VenueReconciled=false` + recorded `AllowFixSend=false`: FIX may be LoggedOn and still cannot debit destination capital. Risk to capital from this process: **NONE** (`SAFE_BY_ABSENCE` of `35=D` plus flags).
- Demo SHADOW only: a bad Achiever book cannot lose live money through this path. Catalog of 8463 does not imply 8463 live tickets.
- VolumeConverter residual: if promotion were later flipped true without dest-grid conversion, Manager `10_000` vs Extended `100_000_000` (or the discarded hundredths `100`) would mis-lot a send. That loss path is **not armed**.

Net: **protecting against live loss, blocking live profit, not protecting profit.** Assigned file is the wrong SUT for the angle.
