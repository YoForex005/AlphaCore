## Profit implication

Hard-false **blocks** live profit. It does **not** protect it.

- 8463 catalog accounts cannot become destination LIVE books through this pin. `DealIngestionService` only writes groups/accounts/deals/positions.
- `ReconstructionScoringService` will persist Achiever `SHADOW` (high quality, low risk) as paper/`SHADOW_ONLY`. Winner tape is not copied as real cTrader exposure.
- Starwave `deals-done scored 0` means that book is not even in `RebuildTraderAsync` this pass; zero chance of a live harvest from that cohort.
- Dashboard dest real P&L is **structurally 0**, independent of source PnL quality. FIX LoggedOn does not create fills.
- There is **no live profit book to protect**. Opportunity cost is the entire destination book.

If the question is “does hard-false keep us from giving back open dest profit?” — no: dest realized is 0. If the question is “does it keep us from spraying a negative source book onto Pepperstone and calling that profit?” — **yes, accidentally**. Copy-all of the measured scored XAU book is **net negative six figures**. That is capital protection mislabeled as profit protection. The SHADOW head (+~$78k source in prior measure) is still not dest profit until a sized, gated send exists.

## Lower-loss implication

Hard-false **does** lower loss (capital protection), together with other off-switches — **not** because this file evaluates LIVE then denies it.

- N=3 early evidence cannot auto-promote. Architecture / `docs/scoring.md` require SHADOW max. The pin is **stricter than required** (false for every state / every N).
- Application never calls `CanPromoteToLive`. Persist will copy whatever `SuggestedState` is. Safety today is “LIVE is not in the reachable set,” not “a gate evaluated LIVE then denied.”
- **Application hole:** if `FromBaseline` later returns `LIVE` and this file is left as-is, `CurrentState` becomes LIVE and `PersistDemoShadowAsync` still will not write a CopyIntent (state != SHADOW). CopyTradingService still cannot send (`NewOrderSingleImplemented=false`, `REAL_COPY=false`). The named pin is **not** what stops the row.
- `REAL_COPY=false` + no NewOrderSingle builder: FIX may be LoggedOn and still cannot debit destination capital. Risk to capital from this process: **NONE** (`SAFE_BY_ABSENCE` of `35=D` plus flags).
- Demo SHADOW only: shadow PnL is Σ slippage (or 0 with empty quote tape), not real P&L. A bad Achiever / Starwave book cannot lose live money through this path.
- Copy-all would *increase* loss: RISK_BLOCKED tail (~−$242k) dominates SHADOW head. Leaving promotion hard-false is the correct loss floor until risk/recon/RBAC exist.

Net: **protecting against live loss, blocking live profit, not protecting profit.** Assigned file is the persist hop, not the pin.
