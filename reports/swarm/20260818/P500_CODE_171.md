## Verdict

**YES_WOULD_LOSE_IF_COPY_ALL; LIVE_NO_DEST_PNL; SAFE_BY_ABSENCE**

Copying **every scored XAU trader** would be a **negative-expectancy destination book** *if* send were armed:

1. **`RISK_BLOCKED` is a loser-shape, not a rank.** Law: `risk >= 80` **or** `(Martingale ∧ MaxDrawdown > 0 ∧ NetPnl < 0)`. Fixture is three doubling losers (`0.10 → 0.20 → 0.40` lots, −100/−200/−400). Copying that bucket copies size-up-after-loss gold.
2. **`docs/risk.md` never excludes those names.** “Every trade request is evaluated against all limits **before** submission.” Limits are % DD, lot/position/trade counts, slip — not `CurrentState`. Dominated-tail book ⇒ the 100-trade daily breaker fills **FIFO with blocked-quality names**.
3. **The documented stop is too late.** Daily-loss kill = 5% from day-start equity, positions **stay open**. Total-loss flatten = 10% from initial balance, then market-close everything. Copy-all of a martingale-tail book eats the first 5–10% **by design**, then either sits in open losers (kill) or crystallizes them at the worst print (flatten).
4. **Timing + slip make XAU copy-all worse.** 100–2000 ms delay on gold martingale adds = late fill. 30-point slip tolerance is large. Stale after 2000 ms is “logged but not executed” — a latency reject, not a quality filter. The first 2 s of a size-up still go through.
5. **This file is looser than the unused/sidecar engine.** Doc: **50 lots / 25 positions / 100 trades / 30-pt slip**. Code `RiskLimits`: **5 lots / 20 positions / $500 per-trader / $2_000 daily / $3_000 portfolio / 20 gross / 10 net**. Following the assigned doc would let **more** of a `RISK_BLOCKED` book through than `RiskEngine` would. Engine still has **no** `TraderState` field and never emits `TRADER_RISK_BLOCKED`.
6. **Volume note is internally inconsistent.** “Hundredths of lots (50000 = 5.0 lots)” cannot coexist with `MT5_VOLUME_SCALE=10000`. Blind copy-all with the wrong scale would **size** the martingale book wrong (second loss channel).
7. **Product does not copy-all today.** Store: `state != SHADOW` → no demo persist. Service allow-list is `{SHADOW, LIVE_CANDIDATE, LIVE}` — **not** `RISK_BLOCKED`. Persist `AllowFixSend = false`. `NewOrderSingleImplemented = false`. `VenueReconciled = false`. `CanPromoteToLive => false`. SHADOW is **all demo**. Starwave scored **0**. `destinationRealPnl` is constructor literal **0**. `REAL_COPY` is false.

**Live Pepperstone / cTrader capital is not being lost today.** FIX LoggedOn is session paint (`35=A`), not a fill. This slot did not build or send `35=D`.
