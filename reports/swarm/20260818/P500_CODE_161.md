Martingale is blocked **only if the caller sets `MartingaleFlag=true`**. Abnormal size is the same pattern (`AbnormalSizing`). Loss / daily-loss / portfolio-DD checks apply to **every** action, so a red dest day **cannot exit** through this method (A71 G21–G23 fail).

**Current dest is not losing.** `AllowFixSend` requires `RealExecutionEnabled` (caller pin `REAL_COPY false`). The empty `if` on lines 90–93 does not reject — it still `APPROVE`s. Unit `Real_flag_false_never_allows_fix_send` asserts `Outcome=Approve` and `AllowFixSend=false`.
