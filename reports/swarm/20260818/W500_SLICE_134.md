## 3. No-loss implication

`MT_RET_AUTH_MANAGER_IPBLOCK` (1012) is a **Manager authentication deny**. This file never calls Manager `Connect`, so it cannot emit 1012, cannot open an Achiever session, and cannot move Achiever equity.

On the FIX side the only outbound message is Logon `35=A`. The service:

- skips all I/O when `CTRADER_FIX_PASSWORD` is missing / placeholder,
- writes `_runtime.RealCopyEnabled = false` after any probe,
- logs `NewOrderSingle still disabled`,
- persists `FixSessionState` status only.

There is no `35=D`, no `OrderQty`, no cancel/replace. A TLS failure or venue reject stays on `LoggedOn=false` / `Status=Error|Disconnected`. Pepperstone cTrader FIX is not on the Achiever Manager IP allow-list; omitting `ACHIEVER_PROXY_*` here is **correct**, not a missed hop.

**Risk to capital:** none from this file on the proxy / 1012 angle. Do not treat a successful FIX `35=A` as Achiever Manager live, and do not pipe this socket through the Achiever HTTP proxy.
