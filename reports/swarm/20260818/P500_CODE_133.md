## Angle

Are the martingale and averaging **filters** in `docs/ctrader-fix.md` strong enough to cut the left tail of copied or would-be-copied XAU books — same-position grid / double-down / add-at-worse-price blow-ups — given live census 8463 accounts, Achiever scoring, Starwave deals-done scored 0, SHADOW-all-demo, dest real P&L 0, FIX LoggedOn, `REAL_COPY` false?

“Filter” here means a gate that **removes** a recovery/grid book from dest size or from `NewOrderSingle`. A venue description, a 30-point slippage **flag**, and a kill-the-send flag are not martingale/averaging filters.

This file is the FIX hop contract. If those filters are not here, the execution venue will not cut the left tail even if scoring/risk elsewhere tags it — unless a **different** layer refuses the intent before this hop.

## Verdict

**FAIL — no. Martingale and averaging filters in this file are not strong enough to cut the left tail, because they do not exist.**

What the document actually specifies:

- **Copy policy on this hop:** “winning trades are copied.” There is no definition of winning, no `WasAveragedDown`, no inter-trade 1.25× lot step, no `MartingaleFlag`. A recovered grid that prints a net-positive last ticket is still a “winning trade” under this sentence and is eligible for 35=D.
- **Pre-trade check:** local order book is for **price validation**, not for same-side add-worse-than-VWAP or lot-multiplier detection.
- **Send path:** `NewOrderSingle` with ClOrdID, symbol, side, quantity, price. Quantity is whatever the copy request already chose. No remaining-lot cap, no SL requirement, no add-count cap.
- **Post-fill:** slippage **flag** at 30 points and unreconciled **alert**. Flags do not unwind a doubled basket and do not pause the source trader.
- **Unknown state:** never re-submit — that cuts **duplicate** dest size on a lost ExecRpt, not a martingale left tail on the source book.
- **Live-send latch:** `REAL_COPY_EXECUTION_ENABLED=false` simulates. That is **SAFE_BY_ABSENCE** of dest fills, not a behavior filter. It is orthogonal to averaging/martingale.

Live census does **not** rescue this file:

- **8463** source accounts can still run grids on the challenge side. This doc will copy any intent the pipeline hands it.
- **Achiever scoring** is not mentioned. Starwave **deals-done scored 0** is not mentioned. Unscored left tail is invisible here.
- **SHADOW all demo** + `destinationRealPnl` **0** + `REAL_COPY` **false** means dest left tail is cut by **not sending**, which this file’s last bullet documents — not by martingale/averaging strength.
- FIX **LoggedOn** matches this file’s session model (QUOTE+TRADE). Logon without a behavior reject is session health, not a left-tail cut.

Do **not** treat FIX LoggedOn + this document as evidence that recovery books are filtered. They are not specified here.
