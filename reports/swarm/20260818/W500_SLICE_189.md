## File

`D:/Prop/mt5-sdk/vendor/MetaTrader5SDK/Include/MT5APIManager.h` is the MetaQuotes Manager API C++ header (copyright 2000-2026, `MTManagerAPIVersion 5570`, date `30 Jan 2026`). It is vendor SDK, not product C# hosting.

It declares:

- `MTProxyInfo` (proxy enable/type/address/auth fields)
- `IMTManagerSink` / `IMTDealerSink`
- `IMTManagerAPI` (manager pumping, connect, groups, users, deals, positions, orders, ticks, dealing, settings)
- `IMTAdminAPI` (admin connect, server/config CRUD, same trade-data surfaces)
- `CMTManagerAPIFactory` (loads `MT5APIManager64*.dll` via `LoadLibraryW` / `GetProcAddress`, creates manager/admin, license-check via CryptoAPI)

It never constructs `WebApplication`, never calls `WebApplication.CreateBuilder` / `Host.CreateApplicationBuilder`, and never opens a dotenv / `.env` file.

## Angle

Assigned defect: a dotenv / `.env` file is not applied to the process environment **before** `WebApplication.CreateBuilder(args)`, so `IConfiguration` would miss keys that exist only in a file.

That ordering can only fail (or succeed) in a **host `Program.cs`**. It cannot originate inside a native C++ vendor header. Empty PASS is therefore the correct slice verdict after actually reading the file — not a skipped review.
