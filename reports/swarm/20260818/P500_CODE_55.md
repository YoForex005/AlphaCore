## Verdict

**FAIL — NO. Sub-3-minute gold scalps would not survive FIX latency plus destination spread as a copy-profit strategy.**

Five independent, measured reasons:

1. **There is no dest fill tape to survive on.** Assigned file: `REAL_COPY_EXECUTION_ENABLED` **false (forced)**; live `35=D` NewOrderSingle **OFF — method does not exist**; copy intents **SHADOW-only**. Survival of a live gold scalp cannot be claimed when nothing is sent.
2. **A 3-minute hold cannot outlive a 3-minute FIX gap.** Architecture §63 / A53: if TRADE is down for 3 minutes while 20 source opens print, reconnect must emit **0** `NewOrderSingle`. Lab OPEN cap is `MaxSourceSignalAge = 15 s`. A scalp that lasts 90–180 s is already inside the catch-up reject window. Achiever ingest rides a **whitelist HTTP proxy** (assigned file); that hop plus scoring delay makes `SIGNAL_STALE` the honest OPEN outcome for a sub-3-minute book.
3. **Dest spread + modeled lag eat the typical scalp target.** Shadow charges dest touch (long=ask / short=bid) and adds **0.05** XAU points when `modeledDelay > 250 ms`. `MaxAllowedSpread = 2.0` still **allows** a 2-point dest book. `MaxPriceMove = 3.0`. A sub-3-minute gold scalp that aims for tenths-to-low-single-digit points is dead at dest half-spread alone, even before 0.25–5 s healthy source-to-fill (A73) or Achiever proxy RTT.
4. **Hold time is recorded and then ignored.** `AverageHoldSeconds` is computed from `ClosedAt - OpenedAt`. `FromBaseline` never reads it. A 60–90 s gold scalp can still land `SHADOW` if `quality >= 70 && risk < 40`. There is no “reject scalp holds” gate.
5. **Starwave cannot contribute a hold-time book this run.** Hosted scoring walks `ListLoginsWithDealsAsync` only. Caller pin: Starwave deals-done scored **0**. Those 1948 Starwave logins (478 open positions) have **no** scored `AverageHoldSeconds`. Any future copy set is Achiever-skewed and unmeasured for scalp duration.

FIX QUOTE+TRADE **LoggedOn** in the assigned file is session-up after tag 553 = integer account id. Logon + `35=D` OFF is **not** a measured source-to-fill histogram that gold scalps can “survive.” Quote session up ≠ fresh dest book (A72/A25: LoggedOn is not `quote_age`).
