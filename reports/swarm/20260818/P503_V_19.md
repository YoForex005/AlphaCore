## 5. Adversarial residuals (do **not** flip the assigned FAIL gate)

These are real holes. They are **not** “remove/flatten missing.”

### 5.1 Re-ADMIT oscillation (loser can **return** next tick)

`onRoster` is only `Status == "ADMITTED"`. After `REMOVED:CONSECUTIVE_LOSSES_3` / `REMOVED:DRAWDOWN_FROM_PEAK`, the next 20 s tick sees `alreadyOnRoster=false`. Streak and DD checks are **skipped**. If `IsTraderEligible` is still true (net still `> 0`, n≥20, SHADOW, demo), `Decide` returns **`Admit`** and L160 writes `ADMITTED` again.

So: same-tick confirmation holds; **latch is missing**. A still-green 3-loss or 40% give-back book is off the roster for ≤20 s, then back on. `ExecuteDemoCopyAsync` will then open dest again.

This is `EXISTS_NEEDS_REFACTOR`, not `MISSING` remove.

### 5.2 First ADMIT ignores streak / DD

T4–T6 require `alreadyOnRoster`. A first-seen name with n≥20, net>0, last 3 losers, or 40%+ give-back is **`AUTO_ADMIT`**. They spend one full cycle `ADMITTED` until the next tick removes them. Policy `IsTraderEligible` does not encode streak/DD.

### 5.3 Venue flatten of dest after REMOVE is not executed

`ExecuteDemoCopyAsync` closes ledger dests only when the **source** reconstructed trade is `Completed` (L521–524). It never reads `FLATTEN_LOSS_CUT`. A removed loser with **still-open** source tickets leaves dest fills (`DemoCopyLedger`, `D:\Prop\data\demo_copy_ledger.json`) open until the source closes or a human sends.

Roster membership is still `REMOVED`. Dest residual ≠ “left on the roster.” It **is** dest flatten **as a send** incomplete.

### 5.4 Orphan `ADMITTED` if the score row disappears

`TickRosterAsync` iterates `TraderScores` only. `ExecuteDemoCopyAsync` iterates `ADMITTED` roster rows. A score delete / never-scored manual `ADMITTED` row is never `Decide`d and stays copyable. No product path was seen that inserts `ADMITTED` except `TickRoster` Admit.

### 5.5 Policy-only skip is not remove

If `TickRoster` is not run, `GenerateShadowIntentsAsync` `IsTraderEligible` `continue`s a red book but **leaves** `Status=ADMITTED`. Production host **does** run TickRoster first. Isolated API does not expose TickRoster.

### 5.6 No hop test

`tests/` has **zero** references to `TickRosterAsync` / `CopyTradingService`. Domain facts cannot prove the persist overwrite or the `ADMITTED` hopper.
