## 4. No-loss implication

**None from this angle on the current Windows API host.** `DealIngestionService` does not send FIX `NewOrderSingle`, does not call MT5 `DealerSend`, and does not size or arm live copy. It only pulls catalog / deals / positions through `IMt5BrokerConnector` and upserts them.

Because the API **is** `net8.0-windows` + `PlatformTarget` x64 and the MetaQuotes trio **is** next to `TraderIntelligence.Api.exe`, the hypothesized “DLL cannot load → empty/stale book → bad live state” blocker is **not** present on the intended Windows process. Load can still fail for other reasons (wrong OS, leftover `net8.0` exe, Linux compose, missing credentials), but those are not “API TFM is not net8.0-windows x64.”

A successful or failed Manager `Initialize` in the connector does **not** place capital. This file never constructs an order.
