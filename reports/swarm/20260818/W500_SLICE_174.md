## 3. No-loss implication

`MT_RET_AUTH_MANAGER_IPBLOCK` (1012) is a **Manager logon deny**, not a fill. This architecture file:

- sets **Execution default: Disabled** until shadow/reconciliation/risk are proven (L7);
- sample env has `REAL_COPY_EXECUTION_ENABLED=false` (L2101);
- §62 forbids opening new copied positions from stale/unavailable source data;
- §68/§70 (live `NewOrderSingle`) stay behind explicit gates;
- final line: real order submission remains OFF until shadow, reconciliation, sizing, and risk-engine gates pass (L2867).

A 1012 therefore **cannot** open, close, or resize destination risk **from this spec’s defaults**. It blocks Achiever ingestion. That is fail-closed for capital.

Residual harm is **operational honesty / Phase 1 completeness**, not size:

1. “Optional proxy” + “Continue retrying” teaches operators to hammer `Connect` while egress ≠ allow-list.
2. Phase 1 can be stamped `Achiever connected` from FakeMt5 / catalog paint / a different SNAT host, while this LAN is 1012 (C42 / R012).
3. If copy is later enabled while Achiever is still IP-blocked, §62 is the only brake — and it never names 1012 as the stale-source cause.

**Risk to capital:** none from 1012 under this document’s default-off execution. Do not treat “Achiever connected” as proven on a host that does not present `81.29.145.69`. Do not treat TCP `:443` OPEN as Manager auth.

## 4. Verdict

**FAIL.** Architecture v2 documents the Achiever allow-list IP and a secret-safe HTTP proxy stanza, but fails the assigned angle:

1. **Zero** mentions of `1012` / `MT_RET_AUTH_MANAGER_IPBLOCK` in 2868 lines.
2. §7 “If proxying is required” + §56 “# Optional proxy” contradict §7 “Required whitelisted outbound IP” for any worker whose egress is not already `81.29.145.69` (measured 1012 path).
3. No `ProxySet` / `PROXY_HTTP` / “TCP open ≠ auth” law.
4. §62 “Continue retrying” without a 1012 branch is an infinite IP-block loop.
5. Phase 1 / §58 / §60 / §73.D have no 1012 or proxy-applied acceptance, metric, test, or risk item.

Empty PASS is **not** used: the file was fully read; the angle applies to this spec.
