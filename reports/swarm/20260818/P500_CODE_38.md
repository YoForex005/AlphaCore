## Profit implication

- **+$100 challenge NET is a source ranking signal, not dest expectancy.** This host will score that book (if it has deals) and may land `SHADOW` via `NetPnl > 0` → **+15** quality. It will **not** print destination fills. Live `destinationRealPnl` remaining **0** is the honest profit statement for slot 38.
- **Venue costs eat a $100 challenge print quickly.** Source commission/swap (if any) are challenge-broker economics. Dest spread 0.25–0.50 on 0.10 lot XAU (≈ 10 oz) is on the order of **~$2.50–$5/side** before dest commission. Ten copied round-trips can consume **$30–$100+** of that print before any residual. News-wide gold spreads consume it in one clip. This host never subtracts that residual.
- **8463 Achiever catalog accounts** will contain many small-positive challenge nets (2-step / payout theater). Scoring all deal-bearing logins **without** a dest-cost filter **ranks cheap-tape luck**. Copying the top of that list would buy demo fill quality, not Pepperstone edge.

- **FIX LoggedOn does not mint profit.** Session-on + `REAL_COPY` false + no `35=D` builder ⇒ dest realized stays 0.
- **Profit action:** do **not** size, copy, or advertise +$100 challenge winners off this ingest. Keep `REAL_COPY` false. Treat dest real PnL **0** as “no harvest,” not “flat and safe to turn on.”
