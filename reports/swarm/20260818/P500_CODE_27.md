## Profit implication

**Hard-false does not protect profit. It also does not currently block measured profit, because measured dest profit is already 0.**

| Path | Profit effect now |
|---|---|
| Achiever scoring | Can write SHADOW / WATCH / EARLY_SCORE / RISK_BLOCKED / INSUFFICIENT_DATA. **No dest fills.** Source-book edge is **not** copied to cTrader. |
| Starwave deals-done scored 0 | **No score rows** from that book. Promotion pin never runs. **Zero** opportunity cost from this function; the deals table is empty. |
| SHADOW all demo | Simulated slippage only (`ShadowPnl` = sum of `SourceVsShadowSlippage`). That is **not** cash. |
| `destinationRealPnl` | Hardcoded **0**. Dashboard cannot show dest profit even if a LIVE row appeared. |
| FIX LoggedOn + `REAL_COPY false` | Quotes/session may be up; **no** NewOrderSingle. LoggedOn ≠ P&L. |

If a later change (a) makes `FromBaseline` return `LIVE` and (b) wires `CanPromoteToLive` as the only remaining refuse, then this stub **would block** destination profit until an audited R6+approve exists. That is the **intended** future cost of the pin. It is not today’s P&L driver.

Flipping the stub to `true` **without** a send path, risk hop, and dest fill ledger would still leave dest P&L at 0. Do not flip it to “unlock profit.” There is no profit path behind the door.

## Lower-loss implication

**This is the real job of the hard-false: keep 8463 cataloged accounts from becoming live copy risk.**

| Layer | Loss prevented |
|---|---|
| `CanPromoteToLive => false` | Named API cannot authorize LIVE. Safer than a premature R6. |
| `FromBaseline` reachable set | Even a high-quality 3-trade book lands **SHADOW**, not LIVE. Unit lock: three winners → SHADOW. |
| Persist hole | Application **does not** consult the pin. Safety today is “FromBaseline forgot LIVE,” not “persist refused LIVE.” A future `return LIVE` would write LIVE **without** this check. |
| `PersistDemoShadowAsync` | Non-SHADOW states write an outbox ScoreUpdate and **return**. Only SHADOW creates `SHADOW_ONLY` intents. No dest qty. |
| `REAL_COPY=false` + no `35=D` | Independent **SAFE_BY_ABSENCE**. Session LoggedOn cannot spend capital from this process. |
| Starwave scored 0 | No shadow intents from that book either. |

**Risk to capital: NONE** from this pin and from this ingest file. Catalog of 8463 accounts is observation. Copy is demo SHADOW. Dest P&L is a literal 0.

**Honesty residual:** do not treat hard-false as the A22 live gate. Persist is blind. The pin is **DEAD** in product callers. Lower-loss is **defense in depth by absence**, not a closed promotion machine.
