Live measured: that bucket is **−$241,580** vs SHADOW **+$78,276** and WATCH **+$8,178**. The blocked tail is larger than the SHADOW head. All-scored source EV is **−$154,425**. Dest costs (Pepperstone spread/commission, 15 s `MaxSourceSignalAge`, gold scalps that die in $2 spread) make copy-all **worse**, not better.

If that policy were live and this engine were the only gate:

1. Dest aligns to **one** metal (no Phase-2 concentration cap here).
2. `RISK_BLOCKED` names are treated as if they were `SHADOW` quality unless `MartingaleFlag` is set.
3. Size-up-after-loss copies whenever the caller forgets the flag, or a `risk>=80` name is not martingale-flagged.
4. Product caller currently **zeros** dest book snapshots, so 10-net / 20-gross / 20-slot brakes **do not accumulate** across intents. A spray would fill until some *other* stop — or until a later caller passed honest exposure.
5. On the first −500 / −2,000 / 3,000 dest day, **refuses to close**.
6. `MaxAllowedSpread=2.0` on gold is ~$200/lot if the unit is dollars — too loose to save a spray.
7. `MaxPositionQuantity=5` is 100× the product `AllocationFactor=0.05`. The engine’s own default is a blow-up size, not a profit size.

Starwave deals-done scored **0** adds **no** XAU edge. Achiever scoring is observation. FIX LoggedOn does not monetize scores. With `REAL_COPY false` and `destinationRealPnl` **0**, there is **no** live dest profit and **no** live dest loss from this file.
