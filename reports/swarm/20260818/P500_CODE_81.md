A copy-every-scored caller that feeds this method identity-blind therefore treats the modal scored class as just another `OpenExposure`.

That modal class is **defined as a losing, size-up-after-loss XAU shape**:

- `risk >= 80`, or
- `Martingale ∧ MaxDrawdown > 0 ∧ NetPnl < 0`.

Under current `BaselineScorer` weights, `risk >= 80` is unreachable without the +35 martingale term (non-martingale max = 20+15+10+10+10 = **65**). So every `RISK_BLOCKED` row is a **martingale** row. Copying them is copying the left tail of retail gold onto one Pepperstone/cTrader XAU dest.

Martingale is blocked here **only if the caller sets `MartingaleFlag=true`**. Caps (`MaxXauGross=20`, `MaxXauNet=10`, `MaxOpenPositions=20`) are last-ditch size brakes on **caller-supplied** snapshots, not a quality screen. **Current dest is not losing.** `AllowFixSend` requires `RealExecutionEnabled` (live `REAL_COPY false`). Product `Evaluate(` callers = this definition + `CopyTradingService` + five unit facts.
