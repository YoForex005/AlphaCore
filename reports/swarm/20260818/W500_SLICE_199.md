## No-loss implication

**None on this path.** A missing `.env` load before `WebApplication.CreateBuilder` cannot originate in this Markdown spec because the file never starts a .NET host, never writes process environment, and never sends FIX `NewOrderSingle`. Architecture law here is: secrets come from **process environment / OS secret store / Vault**; real copy stays **off** until explicit flag + risk-engine health; fail closed when TRADE / DB / quotes are unhealthy. Filling an operator `.env` without exporting those keys is a host/operator concern, not a capital-loss instruction in this document. Worst case of a host that ignores a filled `.env` is missing Manager/FIX passwords → no live logon / fail-closed, not an unsolicited send.
