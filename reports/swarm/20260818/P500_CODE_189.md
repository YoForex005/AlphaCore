## Profit implication

**None from treating SHADOW as a winners list.** Negative `netSourcePnl` SHADOW rows are a **designed-reachable** outcome: quality can hit 70 on a disciplined losing tape, and dashboard `netSourcePnl` can go red on a multi-symbol book whose first-3 XAU still score 95.50.

- `/api/ops/resync` will stamp those logins `SHADOW` and, if a dest quote exists, persist demo shadow fills. That does **not** book Pepperstone / cTrader destination P&L.
- Overview `DestinationRealPnl` is hardcoded **0**. Trader `ShadowPnl` in the row DTO is hardcoded **0**. `shadowPnl` on overview is slippage Σ, not dest profit.
- FIX **LoggedOn** (caller pin) is session state. This file never builds `35=D`. Recon note: `NewOrderSingle still off`. Copy const `NewOrderSingleImplemented=false`. Persist `AllowFixSend=false`.
- `REAL_COPY` **false** (caller pin) is echoed, not enforced here. DI binds the env boolean; even if the lab `.env` is later `true`, this host still has no sender.
- Starwave **deals-done scored 0** means half the 8463-login catalog contributes **no** scored edge. Empty tape → `INSUFFICIENT_DATA`, not a silent profit claim.
- Ranking leak: `/api/traders` sorts `EarlyScore` desc. A 95.50 SHADOW with red `netSourcePnl` outranks a green WATCH. That is a **false profit signal**, not dest-edge after spread / dest commission / slip / qty normalize.

Profit capture, if it is ever built, needs an **explicit** `netSourcePnl > 0` (and XAU-only net, dest-cost haircut, hold-time) conjunct that **does not exist** on this path. This host will not grow one by being mapped.
