## No-loss implication

`ShadowCopyEngine` cannot hide an unscored login from operators and cannot gate live capital on a missing `TraderScore`.

- It never lists, filters, or ranks accounts.
- It never reads `trader_scores`. A login with no score never enters this class unless another layer already classified it `SHADOW` and asked for a paper fill.
- Methods always return a `ShadowFill` / `decimal` MTM; they do not suppress a source account, a dashboard row, or a live order.
- The only product caller writes `CopyIntent` with `Status = "SHADOW_ONLY"` plus a `ShadowOrder`. That is paper slippage, not destination send (no FIX `35=D`, no MT5 dealer confirm).

Worst case inside this type is a bad simulated dest-touch (hardcoded `0.05` overlay when `modeledDelay > 250ms`), not an omitted live account and not a live size. Unscored books remaining invisible in overview **state counts** is an `EfDashboardQueries` grain issue, not a loss path through this engine.

Residual (out of slice): overview score-only counters vs account-driven traders list. Not a defect of `ShadowCopyEngine.cs`.
