## Binding law (this angle)

Architecture v2 §6: `IMt5BrokerConnector.GetAccountsAsync(...)` is the Manager-side account/login census. The Application port must be able to request the **full** manager-visible trader set.

Architecture v2 §7 / §9: `MT5_DEFAULT_GROUP` / `MT5_GROUP_*` must **not** decide which accounts are fetched. Discovery is Manager API (groups → users/logins). Plan labels map after census.

FAIL in **this** file would mean: no census method; a required non-null group that makes ALL inexpressible; a page / take / limit / allow-list on any enumerator signature; or a DTO field that drops logins at the contract layer.
