## Verdict

**NO.** Architecture v2 **requires** shadow pricing on the live cTrader QUOTE FIX book. The product does **not** do that.

What the tile pair actually is:

| Dashboard noun | Binding | What it is today |
|---|---|---|
| Shadow P&L | `OverviewDto.ShadowPnl` | `Σ ShadowOrders.SourceVsShadowSlippage` against a **demo-seeded** `destination_quotes` row (`Bid=2399.45`, `Ask=2399.85`, `VenueInstrumentId=null`). Slippage vs source VWAP, **not** mark-to-market, **not** QUOTE MD. |
| Dest. real P&L | `OverviewDto.DestinationRealPnl` | Constructor literal **`0`**. No dest positions, no dest fills, no FIX ExecutionReport rollup. |

FIX **LoggedOn** is a session bit. It does **not** upsert `destination_quotes`. `CTraderQuoteService` is an unused in-memory mapper (not DI-registered). `CTraderFixLogonHostedService` persists `FixSessionState` only and hard-sets `RealCopyEnabled = false`. The fix-worker restamps QUOTE/TRADE **`Disconnected`** every 15 s and never writes a book.

So: **shadow PnL ≠ real cTrader quotes**, and **`destinationRealPnl` is still zero**. Both halves of the angle fail the architecture law.

- **No destination profit is measured.** `destinationRealPnl` cannot leave `0` without a code change that queries a dest ledger that is not written today.
- Architecture profit target (§3 / §19) is **future execution-venue-net P&L**. That requires Phase 4 live quotes **then** Phase 5 dest-priced shadow **then** (later) Phase 8 fills. Slot 34 is stuck before Phase 4 persistence.
- Ranking 8463 Achiever-scored accounts by source early quality, or treating overview “Shadow P&L” (demo slippage Σ, historically painted **248.20** on the 6-row seed) as copyable edge, **does not create** Pepperstone dollars. It ranks source tape against a frozen 2399 book.
- Starwave deals-done scored **0** adds **zero** dest edge. There is nothing to copy from that broker’s scored book.
- FIX LoggedOn without Security List + MD upsert cannot monetize XAUUSD spread/slippage. You cannot harvest dest edge you never mark.
- Enabling `REAL_COPY` to “start making the dest tile move” would skip §68 (quote persistence, dest cost sample, recon). That is not a profit plan; it is a way to take unmeasured venue risk.

- **Current dest left tail is empty by absence.** `REAL_COPY=false`, no `35=D` builder on the live path, SHADOW_ONLY intents, dest PnL hard-zero. This process cannot lose Pepperstone capital through shadow tiles.
