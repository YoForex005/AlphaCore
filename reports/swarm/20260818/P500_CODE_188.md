## Angle

Does this query layer treat a **+$100 demo / prop-challenge** reconstructed PnL as a tradable destination edge **after venue costs** (cTrader / Pepperstone spread, dest commission, dest swap, source-vs-dest slippage, copy delay)?

Trading law for this slot: **it is not an edge.** Challenge/demo `NetRealizedPnl` is **source-book residual** (often subsidized, differently commissioned, or contest-group economics). Destination XAUUSD costs on even a few lots routinely consume a low-three-digit dollar residual. The dashboard must not present +$100 source as dest profit.

---

## Verdict

**FAIL.** After reading all 217 lines:

1. `GetTradersAsync` ranks and displays **source** completed-trade `Sum(NetRealizedPnl)` as `TraderRowDto.NetSourcePnl`. No dest spread, dest commission, dest swap, dest fee, or slippage overlay is applied. A +$100 Achiever challenge book would appear as **+$100**.
2. That sum is **all completed reconstructed trades**, not XAU-only. A contest residual on any symbol paints the same “Net P&L” column the UI labels as money.
3. `GetOverviewAsync` writes `DestinationRealPnl`, `XauGross`, and `XauNet` as **literal `0`**. That matches the live pin `destinationRealPnl 0`. It is **uncomputed dest book**, not “+$100 minus venue costs = 0.”
4. Overview “Shadow P&L” is `SUM(shadow_orders.SourceVsShadowSlippage)`, not dest realized/unrealized net and not a cost-adjusted challenge PnL.
5. Per-trader `ShadowPnl` is a **third literal `0`**.
6. `GetRiskAsync` hardcodes `DailyPnl`, `Drawdown`, `XauLong`, `XauShort`, `XauNet` to **0**. Dest cost / dest drawdown are invisible.
7. `GetFixSessionsAsync` hardcodes `ExecutionEnabled = false`. FIX LoggedOn can paint quote/trade healthy while dest fills (and dest costs) cannot exist.
8. Last overview flag is `_runtime.RealCopyEnabled` (live pin **false**). This file cannot flip it and cannot send.

Honesty: dest tile `0` is **allowed** while `REAL_COPY` is false. The failure is **edge hygiene** — source +$100 is still the only money number operators see on the trader grid, and it is **not** haircut for venue costs.

This is **not** an empty PASS.

## Why +$100 challenge is not dest edge (applied to this file)

`$100` source net on an Achiever (or other) challenge / demo group is **source-book residual**:

- `ReconstructedTrade.NetRealizedPnl` already nets **source** commission / swap / fees. Those are **not** Pepperstone cTrader costs. Reconstructor `Fees` is hardcoded **0**.
- Destination XAUUSD round-trip spread on even **1 lot** is tens of dollars per 0.10–1.00 lot (100 oz/lot × dest bid/ask). Dest commission and adverse slip stack on top. A +$100 residual is the same order of magnitude as a few dest gold tickets.
- Copy delay + `SourceVsShadowSlippage` is the **first** dest-cost proxy the product stores. This file **does not subtract it** from trader PnL; it either sums it as a global “Shadow P&L” or zeros the per-trader field.
- Seeded dest book (adjacent `DemoSeeder`) is an invented **2399.45 / 2399.85** touch. That $0.40/oz spread is **never** applied to `NetSourcePnl`.
- Adjacent fake Achiever books are explicitly demo/contest groups (`demo\Maxmaster`, `demo\yo-2step`, `contest\yo-2step`). This file passes `GroupName` through and never treats those strings as “not dest edge.”
- Live census: SHADOW **all demo**, Starwave deals-done scored **0**, dest real PnL **0**, `REAL_COPY` **false**. There is **no dest fill** against which +$100 could be validated.
- 8463-account Achiever-heavy scoring plus EarlyScore sort will surface challenge survivors whose source net is +$100-class noise.

Therefore: **+$100 demo/challenge is not an edge after venue costs**, and **this query layer does not implement that law**.
