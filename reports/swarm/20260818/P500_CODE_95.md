2. **A 3-minute hold cannot outlive a 3-minute FIX gap.** Architecture §63: if TRADE is down for 3 minutes while 20 source opens print, reconnect must **not** fire those 20 entries. Lab OPEN cap is `MaxSourceSignalAge = 15 s`. A scalp that lasts 90–180 s is already inside the catch-up reject window; ingest via Achiever’s HTTP whitelist proxy plus scoring delay makes `SIGNAL_STALE` the honest OPEN outcome.
3. **Dest spread + modeled lag eat the typical scalp target.** Shadow charges dest touch (long=ask / short=bid) and adds **0.05** XAU points when `modeledDelay > 250 ms`. `MaxAllowedSpread = 2.0` still **allows** a 2-point dest book. A sub-3-minute gold scalp that aims for tenths-to-low-single-digit points is dead at dest spread alone, even before 0.25–5 s healthy source-to-fill (A73) or the Achiever proxy hop.
4. **The scorer will still SHADOW a 90 s gold book.** `AverageHoldSeconds` is computed and **never read** by `TraderStateMachine.FromBaseline`. Live pin: login 322947 avg hold **~163 s** already labeled as dying in spread + 15 s stale. Starwave is stuck at **deals-done scored 0**, so 1948 of those logins contributed **no** hold-time book this run.

FIX QUOTE+TRADE TLS **logon true** in the assigned file is session-up, not fill quality. Logon + `35=D` OFF is **not** a measured latency that gold scalps can “survive.”
