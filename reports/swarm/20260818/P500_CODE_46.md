## Verdict

**UNIT-TEST ONLY. `QuantityNormalizer` is not wired to any FIX `OrderQty`.**

Reachable facts after reading the assigned hosted service and grepping product source:

1. `CTraderFixLogonHostedService` logs on QUOTE (5211) and TRADE (5212), stamps `LiveRuntimeStatus`, and persists `FixSessionState`. It never imports `TraderIntelligence.Domain.Execution`, never constructs `QuantityNormalizer`, never calls `Normalize`, and never writes tag 38.
2. The same unit **hard-sets** `_runtime.RealCopyEnabled = false` and logs `NewOrderSingle still disabled`. Logon ≠ send.
3. `CTraderFixSession` builds **only** Logon (`35=A`). There is no `35=D`, no `38=`, no `OrderQty` anywhere under `src/Fix.CTrader`.
4. Grep of `D:\Prop\src` for `QuantityNormalizer` = **one hit**: the class declaration in `Domain\Execution\QuantityNormalizer.cs`. Zero callers in Risk, Shadow, Application, Infrastructure, Fix.CTrader, or either worker.
5. `DependencyInjection.AddTraderIntelligence` registers reconstructor, scorer, ingest, and this hosted service. It does **not** register `QuantityNormalizer`.
6. The only `new QuantityNormalizer()` sites are unit tests. Those tests **lock passthrough** (`0.10` lots × allocation 1 → `0.10`) and **skip** the real lots→ounces→`OrderQty` converter (`IQuantityConverter` is missing). Two skipped facts state the wiring gap in plain text: unused by `ShadowCopyEngine` / `RiskEngine`; no FIX NOS builder consumes the output.

If this helper were later dropped onto tag 38 as-is, G7 would FAIL (0.10 MT5 lots would become 0.10 dest qty, not 10 oz on a 100 oz contract). That is a **future** wiring risk. It is **not** live today.

## Adjacent evidence (why this is unit-test only)

### Domain helper — last-stage floor, not a FIX mapper

```9:29:D:\Prop\src\Domain\Execution\QuantityNormalizer.cs
public sealed class QuantityNormalizer
{
    public decimal Normalize(decimal sourceLots, decimal allocationFactor, InstrumentQuantitySpec dest)
    {
        if (sourceLots <= 0)
            throw new ArgumentOutOfRangeException(nameof(sourceLots));
        if (allocationFactor <= 0)
            throw new ArgumentOutOfRangeException(nameof(allocationFactor));
        if (dest.StepSize <= 0)
            throw new ArgumentOutOfRangeException(nameof(dest.StepSize));

        var raw = sourceLots * allocationFactor;
        var steps = decimal.Truncate(raw / dest.StepSize);
        var qty = steps * dest.StepSize;
        qty = decimal.Round(qty, dest.Precision, MidpointRounding.ToZero);

        if (qty < dest.MinQuantity)
            return 0m;
        if (qty > dest.MaxQuantity)
            return dest.MaxQuantity;
        return qty;
    }
}
```

No contract size, no ounces, no convention (`Lots` vs `BaseUnits`), no confidence, no margin, no FIX tag. `sourceLots * allocationFactor` with dest min/step/max. Allocation `1` → **passthrough**.
