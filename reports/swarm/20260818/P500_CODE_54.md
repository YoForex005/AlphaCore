## Verdict

**FAIL — shadow PnL is not live cTrader-quote economics. `destinationRealPnl` is still a constructor literal `0`.**

Assigned architecture **requires** shadow-copy to price from the **cTrader QUOTE FIX** session and to persist `shadow_pnl` / `shadow_performance`. Destination real P&L is a **separate** Overview tile (§47) that must come from the destination book (`destination_positions` / FIX fills), not from source MT5 and not from the shadow tile.

What the product actually paints (read 2026-08-18):

1. **Dest. real P&L** (`OverviewDto.DestinationRealPnl`) is the **second constructor `0`** after the slippage sum in `GetOverviewAsync`. No destination-position query exists. Caller-measured `destinationRealPnl = 0` is the **code path**.
2. **Overview Shadow P&L** is `SUM(shadow_orders.SourceVsShadowSlippage)` — source-vs-touch **slippage**, not realized/unrealized shadow PnL, not `MarkToMarket`, not `shadow_performance`.
3. **Per-trader `TraderRowDto.ShadowPnl`** is a **third** hardcoded `0`. Leaderboard shadow column is dead.
4. The **only** `DestinationQuotes.Add` in `src/` is `DemoSeeder` inventing **2399.45 / 2399.85** with `VenueInstrumentId = null`. `CTraderQuoteService` never persists. FIX logon (caller **LoggedOn**) writes **session status only** and pins `RealCopyEnabled = false`.
5. SHADOW rows exist only via `PersistDemoShadowAsync` (`Status="SHADOW_ONLY"`), matching caller **SHADOW all demo**. Starwave deals-done scored **0** cannot produce a destination book.

FIX LoggedOn + 8463 Achiever-catalog accounts do **not** make the shadow tile a venue quote. Session up ≠ `MarketDataIncrementalRefresh` persisted.
