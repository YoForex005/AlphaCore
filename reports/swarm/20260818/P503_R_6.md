```100:111:D:\Prop\src\Domain\Copy\CopyRosterEngine.cs
    public static int ConsecutiveLosses(IReadOnlyList<ReconstructedTradeResult> closedNewestLast)
    {
        var n = 0;
        for (var i = closedNewestLast.Count - 1; i >= 0; i--)
        {
            if (closedNewestLast[i].NetRealizedPnl < 0)
                n++;
            else
                break;
        }
        return n;
    }
```

| Input | Counts as a loss? |
|---|---|
| `NetRealizedPnl < 0` | Yes |
| `== 0` (scratch / breakeven) | **No — breaks the streak** |
| Open / `Completed=false` | Excluded before the count (`t.Completed && t.IsXauUsd`) |
| Non-XAU | Excluded (`IsXauUsd` is canonical `XAUUSD` only) |

Order of gates on an **already admitted** name: `STATE_*` / `SIZE_PATTERN` / `DEMO_OR_CONTEST` → `XAU_BOOK_TURNED_NEGATIVE` (`net<=0`) → **`CONSECUTIVE_LOSSES_n`** → `DRAWDOWN_FROM_PEAK` (40% of peak) → else KEEP. A 3-loss tail that also dumps net ≤ 0 is labeled `XAU_BOOK_TURNED_NEGATIVE`, not streak. Same `RemoveAndFlatten` payload.

`PAUSED` is an **input**, not an output. If the scorer/operator already paused the name, `Decide` returns `Remove("STATE_PAUSED")` and would flatten dest copies. That is **pause ⇒ flatten**, the inverse of the assigned claim.

## 3. REMOVE implication — not a pause, and not sticky

`onRoster` is **only** `row != null && row.Status == "ADMITTED"` (`CopyTradingService` L118). `REMOVED:CONSECUTIVE_LOSSES_3` is therefore **off roster**.

Next tick, `Decide(..., alreadyOnRoster: false)`:

1. State is still `SHADOW` / `LIVE` (never rewritten).
2. Streak check skipped.
3. If `IsTraderEligible` still true (20+ XAU, **net still > 0**, no martingale) → **`AUTO_ADMIT`**.
4. Hop writes `row.Status = "ADMITTED"` again (L141–143).

Oscillation every 20 s on a still-green book with a 3-loss tail:

```text
ADMITTED → REMOVED:CONSECUTIVE_LOSSES_n + FLATTEN_LOSS_CUT rows → ADMITTED → …
```

`TraderState.PAUSED` exists on the enum (`TraderState.cs` L11) and is rejected by both policy and roster, but **no product file assigns it**. `DealIngestionService` only copies `score.SuggestedState` from `TraderStateMachine.FromBaseline`, which emits `INSUFFICIENT_DATA` / `EARLY_SCORE` / `WATCH` / `SHADOW` / `RISK_BLOCKED` — **never `PAUSED`**.

REMOVE therefore:

- stops new hopper opens **for at most one 20 s tick**;
- also skips the source-close mirror while status ≠ `ADMITTED` (same `continue`);
- does **not** pause the trader;
- does **not** cancel working dest / shadow inventory except via the paper flatten rows.
