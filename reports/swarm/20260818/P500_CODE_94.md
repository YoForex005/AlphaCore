## Verdict

**FAIL — `destinationRealPnl` is still a constructor literal `0`. Shadow “P&L” is not live cTrader QUOTE PnL.**

The assigned architecture file is unambiguous: shadow-copy **must** use the destination **cTrader QUOTE FIX** session for entry/spread/freshness/slippage and must persist `shadow_pnl` / `shadow_performance`. Phase 4 (live XAU quote persistence) is a prerequisite of Phase 5 (destination-quote shadow P&L). §41 **allows** QUOTE logon while `REAL_COPY_EXECUTION_ENABLED=false`. That is the intended shadow state.

The product does **not** implement that law.

What is actually painted:

1. **Dest. real P&L** (`OverviewDto.DestinationRealPnl`) is the **first numeric `0` after `shadowPnl`** in `GetOverviewAsync`. No destination fill, position, or FIX ExecutionReport rollup is queried. Caller-measured `destinationRealPnl = 0` is the **code path**, not a measured flat Pepperstone book.
2. **Shadow P&L** is `SUM(shadow_orders.SourceVsShadowSlippage)` — source-vs-touch **slippage**, not realized/unrealized shadow PnL, not `ShadowCopyEngine.MarkToMarket`, not `shadow_performance` (table **absent**).
3. The **only** product `DestinationQuotes.Add` is `DemoSeeder` inventing **2399.45 / 2399.85** with `VenueInstrumentId = null`. `CTraderQuoteService` keeps bid/ask **in memory** from harness tags `1320/1321` and is **not** called from the logon host. Logon (caller **LoggedOn**) writes **`fix_sessions.Status` only**.
4. SHADOW rows exist via `PersistDemoShadowAsync` (`Status="SHADOW_ONLY"`) and optional `CopyTradingService` when a dest-quote **row** exists. That matches caller **SHADOW all demo**. Starwave deals-done scored **0** cannot produce a destination book.

FIX LoggedOn + 8463 Achiever-catalog accounts do **not** make the shadow tile a venue quote. Session up ≠ `MarketDataRequest` (`35=V`) ≠ persisted `destination_quotes`.
