## 2. Close path is source-close copy, not eligibility-loss flatten

Close intents are created only when **all** of these hold:

1. Trader is still in `{SHADOW, LIVE_CANDIDATE, LIVE}` (otherwise they never enter the foreach).
2. Snapshot still passes `IsTraderEligible` (otherwise `continue` before this loop).
3. Source reconstructed trade is `Completed` and has `ClosedAt`.
4. An `…:open` idempotency key already exists.
5. An `…:close` key does not.
6. `_policy.Evaluate(..., CloseExposure)` **Accept**s.


That loop never runs for a later-`RISK_BLOCKED` login. Residual dest / shadow exposure is left as-is. Prior rows are not cancelled.

The close branch also **does not** call `_risk.Evaluate`. It stamps `Status = "SHADOW_ONLY"` and does not write a `RiskDecisionRecord`. Even a legal source-close is paper-only.
