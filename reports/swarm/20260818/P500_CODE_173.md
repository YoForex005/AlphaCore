## Verdict

**FAIL. Not strong enough.** After reading all 74 lines of the assigned file:

1. `docs/ctrader-fix.md` never mentions martingale, averaging-down, grid, size-up-after-loss, `RISK_BLOCKED`, or any trader-behavior filter.
2. The documented trade path is: MT5 deal → `NewOrderSingle` (MsgType=D) → `ExecutionReport` → reconcile. No score/risk gate appears in that sequence.
3. The only send-side brake in this file is `REAL_COPY_EXECUTION_ENABLED=false` plus “never re-submit unknown state.” Those are **absence / duplicate-order** brakes, not left-tail behavior filters.
4. Adjacent product code *does* detect martingale and averaging, but the detections leak the books that actually blow dest: winning / mild martingale can score `SHADOW`; averaging is a +20 risk add-on and is **not** a `RiskEngine` field; Starwave empty books score both flags `false`.
5. Copy pipeline (`CopyTradingService`) only passes `MartingaleFlag` / `LotEscalation`. `AveragingDown` is dropped. `VenueReconciled` is const `false`, so `MARTINGALE_BLOCK` is not even reached on live intents today.

Honesty: **do not claim** the left tail is cut by martingale/averaging filters. **Do not claim** dest $0 proves the filters work. Dest $0 matches `REAL_COPY` false + `NewOrderSingleImplemented=false` + venue not reconciled. Flip those gates and averaging / slow-grid / same-size recovery still send.

## Profit implication

Profit is **not** “copy winning trades to cTrader” (the assigned doc’s Overview). Challenge-pass books that look green on first-3 / net>0 are exactly the recovery / mild-grid / averaging cohort. Copying them (or copy-all completed XAU of SHADOW logins) is **negative EV** on dest: the next unclosed grid leg is the left tail.

Profit, if any, is:

1. Keep `REAL_COPY` false and NOS unimplemented until filters actually reject averaging, slow grids, same-size recovery, and open scale-ins — not only losing `>1.25×` adjacent pairs.
2. Do **not** treat SHADOW as a send license. SHADOW is “not LIVE,” not “safe hedge.”
3. Tiny dest size (`AllocationFactor = 0.05`) and shadow fills **after** real quotes, then measure shadow EV **including** the blocked tail — not just the green first-3.
4. Starwave scored 0: there is no Starwave edge to monetize. Do not copy it.

Copy-winners / copy-SHADOW-all is a **loss** recipe. The FIX doc’s “winning trades are copied” sentence is the wrong product.
