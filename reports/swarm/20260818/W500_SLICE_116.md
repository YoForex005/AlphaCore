## No-loss implication

`ShadowCopyEngine` cannot hide an unscored login from operators and cannot gate live capital on a missing `TraderScore`.

- It never lists, filters, or ranks accounts.
- It never reads `trader_scores`. A login with no score never reaches this class unless some other layer already classified it `SHADOW` and asked for a paper fill.
- Methods always return a `ShadowFill` / `decimal` MTM; they do not suppress a source account, a dashboard row, or a live order.
- The only product caller writes `CopyIntent` with `Status = "SHADOW_ONLY"` plus a `ShadowOrder`. That is paper slippage, not destination send.

Worst case inside this type is a bad simulated price (hardcoded 0.05 overlay after 250 ms), not an omitted live account. Unscored books remaining invisible in overview **state counts** is an `EfDashboardQueries` grain issue, not a loss path through this engine.
