## Angle

“Scored” = a `TraderScore` / `BaselineScore` exists. Caller pin: Achiever scoring is live; Starwave deals-done scored **0**, so those logins are not an XAU tape this wave. `RISK_BLOCKED` is a **scoring state** (`TraderStateMachine.FromBaseline`), not a `RiskEngine` outcome.

## Verdict

**YES — if that policy were live and those names were actually sent, dest would be expected to lose money.** `RISK_BLOCKED` dominance is a **warning about the source book**, not a filter this engine applies.

`RiskEngine.Evaluate` never sees `TraderState`. There is no request field for `RISK_BLOCKED` / `LIVE` / `SHADOW` / `CompletedXauTrades`. Spec reason `TRADER_RISK_BLOCKED` (A23 §4.3, A71 G20) is **not emitted**. Copy-every-scored therefore includes the modal scored class: martingale + drawdown + **negative NET** (or `risk >= 80`). Those are the books `FromBaseline` labels `RISK_BLOCKED`. Copying them is copying a losing, size-up-after-loss XAU cluster onto one dest gold book.

Martingale is blocked only if the **caller** sets `MartingaleFlag=true`. Caps (`MaxXauGross=20`, `MaxXauNet=10`, `MaxOpenPositions=20`) are last-ditch size brakes on caller-supplied snapshots, not a quality screen. `MAX_XAU_NET` is labeled `ReduceSize` but goes through `Reject()` → `ApprovedQuantity=0` (hard stop, not a clip). Side-blind `abs(net)+qty` treats a hedging add as more net. Loss/DD checks apply to **every** action, so a red dest day **cannot exit**.

**Current dest is not losing.** `AllowFixSend` requires `RealExecutionEnabled` (live `REAL_COPY` false). Product now *does* call `Evaluate` from `CopyTradingService`, but that caller (a) excludes `RISK_BLOCKED` from the copyable set, (b) hard-pins `Reconciled=false` so every `OpenExposure` dies as `VENUE_NOT_RECONCILED` before APPROVE, (c) persists `AllowFixSend=false`, (d) has `NewOrderSingleImplemented=false`. SHADOW is all-demo. `destinationRealPnl` is constructor literal **0**. FIX LoggedOn is session, not send. Starwave scored **0** deals-done.

Do **not** flip `REAL_COPY` and copy every Achiever score. That is the losing path this file fails to stop **by state**.

## Profit implication

**Copy-every-scored-XAU is not a profit path.** The scored class that is **blocked** is defined as a losing martingale (or risk ≥ 80). A book dominated by that class is a **negative-expectancy** source tape. Putting every Achiever score onto one Pepperstone/cTrader XAU dest would:

1. Align dest with correlated gold (one symbol; no Phase-2 concentration cap in this engine).
2. Include the `RISK_BLOCKED` majority as if they were `SHADOW` quality — unless some *other* file remembers the state or the martingale flag.
3. Size up after source losses whenever the caller forgets `MartingaleFlag`.
4. Hit 10 net / 20 gross lots of the **same** metal (if snapshots are honest), then hard-zero further adds — leftover dest stays long/short the losing cluster. If snapshots stay zero (today’s caller), those caps never fire.
5. On the first −500 / −2_000 / 3_000 dest day, **refuse to close**.

Starwave deals-done scored **0** adds **no** XAU edge (and no scored tape). Achiever scoring of thousands of logins is observation. FIX LoggedOn does not monetize scores. With `REAL_COPY` false and `destinationRealPnl` **0**, there is **no** live dest profit and **no** live dest loss from this file. Do not treat “8463 accounts” as 8463 copy candidates. SHADOW names in this wave are **demo only** — not Achiever live edge.

There is **no** measured dest profit to protect. There is a measured **policy hole**: an operator who followed only this engine (no state field) and flipped copy-all + `REAL_COPY` + recon would import the blocked majority.

## Lower-loss implication

**Lower dest loss = do not copy every score. Filter `RISK_BLOCKED` (and `INSUFFICIENT_DATA` / `EARLY_SCORE` / `WATCH`) before any intent.** Keep `REAL_COPY` false until a state-aware gate exists **inside** `Evaluate` (`TRADER_RISK_BLOCKED` on increase; still allow reduce/close).

What this file already does that limits loss **if** a naive copy-all were wired with honest book snapshots:

- `AllowFixSend=false` when `RealExecutionEnabled=false` (today’s measured floor).
- `MARTINGALE_BLOCK` / `ABNORMAL_SIZING_BLOCK` if the caller actually sets the flags.
- Gross 20 / net 10 / 20 slots / 5 lots per ticket — a size ceiling, not a quality filter.
- `Reject` always `AllowFixSend=false`.

What this file does that **worsens** dest loss once a copy-all book exists:

- Ignores `RISK_BLOCKED` (the dominance signal).
- Freezes reduce/close at trader-loss / daily-loss / portfolio-DD.

- No dest identity — cannot flatten what it approved.
