## 3. REMOVE path — later RISK_BLOCKED is a query miss, not a roster action

Sequence if a login was SHADOW (or LIVE*) when an `:open` intent was written, then scoring later stamps `RISK_BLOCKED`:

1. Next hosted tick: `Where(s => copyable.Contains(s.CurrentState))` **omits** the row.
2. The `foreach (var score in scores)` body never runs for that login.
3. No new `:open` idempotency key is considered (good: no ADMIT).
4. The completed-trade close loop (L253–294) also never runs (bad: no REMOVE-close, no FLATTEN).
5. Existing `CopyIntent` / `ShadowOrder` / (hypothetical dest fill) rows are left as-is. Status is not rewritten. `RiskDecisionRecord` is not appended. No `RemoveAndFlatten` reason is persisted.

There is no “already on roster” bit. Idempotency keys `copy:{broker}:{login}:{position}:open|close` are the only memory of prior copy. They are **not** scanned for owners who left the copyable set.

`GetStatusAsync` counts LIVE / SHADOW / WATCH only (L38–40). Blocked names do not appear as a flatten-pending gate.

**REMOVE implication:** new exposure stops. Old dest/shadow exposure is **not** removed. This is `AllowNewOpens=false` by absence, not `RemoveAndFlatten`.

## 4. FLATTEN path — does not exist on the product hop

### 4.1 What a flatten would have to be

Law (roster comment L31; A48 / dest-only flatten): close **known destination remaining** on the one cTrader execution login. Never `DealerSend` the MT5 source. Qty = dest remaining, not source lots.

### 4.2 What CopyTradingService emits instead

**Open** (L123–251): for `!t.Completed` XAU tickets of still-eligible copyable scores. `CopyIntentAction.OpenExposure`. Evaluate with `KillSwitch = KillSwitchMode.None` (L192). Persist `AllowFixSend = false` (L211). Shadow `SimulateEntry` only if quote exists **and** `Approve`.

**Close** (L253–294): only if

- trader is **still** in `{SHADOW, LIVE_CANDIDATE, LIVE}` **and** still policy-eligible, and
- the reconstructed ticket is `Completed && ClosedAt.HasValue`, and
- `:open` intent already exists, and
- `:close` intent does not.

Then it writes `CopyIntentAction.CloseExposure` with `Status = "SHADOW_ONLY"`. **No** `RiskEngine.Evaluate` on close. **No** dest venue id. **No** FIX send.

A later-`RISK_BLOCKED` trader fails the first bullet, so source close is **not** copied either. Dest (if it had been filled) stays open after the source is gone **and** after the trader is blocked.
