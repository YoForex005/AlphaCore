Architecture §39 names “max loss per selected trader.” It does **not** assign `500`. `new RiskEngine()` (and `CopyTradingService`’s `private readonly RiskEngine _risk = new();`) use the constructor default. **No binder** from `appsettings.json` `RiskEngine:*` — that catalog is a **different** set (`MaxDailyDrawdownPct`, `MaxPositionSize`, `KillSwitchEnabled`) and **does not name** `MaxLossPerTrader`. `SettingsController.Get` also omits the dollar cap. `docs/risk.md` (“Max Daily Loss 5%”) is **not** this engine.

DI registers an unused singleton (`DependencyInjection.cs` L45). The product hop does **not** consume it.

### 1.2 Predicate is unguarded (all actions)

```117:118:D:\Prop\src\Domain\Risk\RiskEngine.cs
        if (request.TraderRealizedLoss <= -_limits.MaxLossPerTrader)
            return Reject(request, RiskDecisionOutcome.PauseTrader, "MAX_LOSS_PER_TRADER");
```

Measured properties:

| Property | Measured |
|---|---|
| Compare | `<=` — fires at **exactly** `-$500` |
| Action filter | **None.** Unlike quote/spread/size/martingale (all `&& IsIncreasing`), this line has **no** `IsIncreasing` / `IsReducing` guard |
| Outcome | `PauseTrader` (enum 3) — **not** `GlobalStop`, **not** `EmergencyFlatten` |
| Qty / send | `ApprovedQuantity = 0`, `AllowFixSend = false` via `Reject()` (L180–188) |
| Side effect | **None.** No latch, no dest close, no source close, no `KillSwitchMode` write |
| Input | Caller-supplied `RiskEvaluationRequest.TraderRealizedLoss` (L47). Engine does **not** load dest book, dest fills, or source login PnL |

`IsIncreasing` = `OpenExposure | IncreaseExposure`. `IsReducing` = `ReduceExposure | CloseExposure`. The reducing branch (`RISK_REDUCTION` Approve, L152–161) is **unreachable** once `TraderRealizedLoss <= -500`.

That is the A71 §14 defect: “`TraderRealizedLoss`, daily PnL, portfolio DD apply to **all** classes (lines 117–124). **Would freeze exits on a losing day.** CLOSE family must pass.”

### 1.3 `EmergencyFlatten` is a different switch


## 2. Not “per copied trader”

“Per copied trader” would mean: one dest-side cumulative loss bucket **per source login being copied**, updated from dest fills / dest MTM.

Product hop:

```178:201:D:\Prop\src\Infrastructure\Copy\CopyTradingService.cs
                var decision = _risk.Evaluate(new RiskEvaluationRequest
                {
                    // ...
                    SourceLogin = score.Login,
                    Action = intent.Action,          // always OpenExposure here
                    // ...
                    KillSwitch = KillSwitchMode.None,
                    TraderRealizedLoss = Math.Min(0m, trade.NetRealizedPnl),
                    DailyExecutionPnl = 0,
                    PortfolioDrawdown = 0,
                    CurrentGrossXau = 0,
                    CurrentNetXau = 0,
                    OpenPositions = 0,
                    MarginUsage = 0,
                    MartingaleFlag = score.Martingale,
                    AbnormalSizing = score.LotEscalation
                });
```

| Required “per copied trader dest stop” | Product hop |
|---|---|
| Dest realized (or MTM) for that source login on Pepperstone | **No.** `trade.NetRealizedPnl` is **one reconstructed source ticket** |
| Sum of that trader’s completed XAU (the hop already has `XauNetPnl`) | **No.** Snapshot computes `xau.Where(t => t.Completed).Sum(t => t.NetRealizedPnl)` at L114 and **does not pass it** |
| Sign convention = dest loss (negative) | `Math.Min(0m, …)` clamps profits to 0; a **winning** source ticket never “credits” the cap |
| Which trades are evaluated | Only `xau.Where(t => !t.Completed)` (L123) — **open** source positions |
| Open-ticket `NetRealizedPnl` | Reconstruct `GrossRealizedPnl + Commission + Swap` (`TradeReconstructor` L332). For a still-open ticket this is **partial-close + fees**, **not** mark-to-market |
| Dest book / dest daily | Forced `0` (`DailyExecutionPnl`, `PortfolioDrawdown`, gross/net XAU, open count) |
| Persist `AllowFixSend` | **Hard-forced `false`** (L211) regardless of `Evaluate` |

So the $500 line, on the only product caller, is “has **this one still-open source ticket** already realized `<= -$500` (partials + swap)?” — not “has **this copied trader’s dest book** lost $500?”

A trader with ten open tickets of −$400 each (source) never trips the cap. A trader whose dest already lost $5,000 never trips it, because dest PnL is not an input.

## 3. Not “on each tick”

Three clocks exist. None is a market tick into `RiskEngine`.

| Clock | What it is | Calls `Evaluate`? |
|---|---|---|
| MT5 `IMTTickSink::OnTick` (`mt5-sdk/src/core/mt5_tick_bridge.*`) | SDK pump thread; enqueue-only; **must not** DB/FIX | **No.** C++ bridge has zero `RiskEngine` references |
| FIX QUOTE tape | Would refresh `DestinationQuotes` | **No** `Evaluate` caller. Quote is read once per poll as `OrderByDescending(ReceivedAt).FirstOrDefault` |
| `CopyTradingHostedService` | `Task.Delay(8s)` then loop `GenerateShadowIntentsAsync` + **`Task.Delay(20s)`** | Only when the poll **creates a new OPEN intent** |

Hosted “tick” is a **20-second poll**. The log line `"Copy pipeline tick failed"` (L34) is that loop, not `OnTick`.

Inside `GenerateShadowIntentsAsync`:

1. Eligible scores: `SHADOW | LIVE_CANDIDATE | LIVE` only.
2. Per open XAU ticket: idempotency key `copy:{broker}:{login}:{positionId}:open`. If a row exists, **`continue` — `Evaluate` is not called again**.
3. Persist `AllowFixSend=false`; status `SHADOW_ONLY`.
4. Close loop (L253–295): writes `CloseExposure` intents **without** calling `_risk.Evaluate` at all.

So even the 20 s poll does **not** re-apply `MaxLossPerTrader` to an already-copied position as price moves. First OPEN create = one evaluation. Later ticks, later polls, MTM, dest PnL: **never**.

Unit tests never assert this line. `RiskEngineTests.Base` hard-sets `TraderRealizedLoss = 0`. Zero facts name `MAX_LOSS_PER_TRADER`.
