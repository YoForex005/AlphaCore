## 2. Domain: `CopyRosterEngine` auto-removes losers

Class law (`CopyRosterEngine.cs` L29–31): *Auto-admit eligible XAUUSD traders and auto-remove losers. Flatten is destination-only. Never touches the MT5 source book.*

`Remove(...)` is always REMOVE **and** dest flatten:

```128:135:D:\Prop\src\Domain\Copy\CopyRosterEngine.cs
    private static RosterDecision Remove(string reason) =>
        new()
        {
            Action = RosterAction.RemoveAndFlatten,
            Reason = reason,
            FlattenDestination = true,
            AllowNewOpens = false
        };
```

Loser / eject triggers (all `RemoveAndFlatten`):

| Condition | Reason | On-roster required? |
|---|---|---|
| `RISK_BLOCKED` / `DISQUALIFIED` / `PAUSED` | `STATE_*` | No |
| Martingale / averaging-down / lot-escalation | `SIZE_PATTERN` | No |
| Group not demo/contest path segment | `NOT_DEMO_OR_CONTEST_GROUP` | No |
| Completed XAU `net <= 0` | `XAU_BOOK_TURNED_NEGATIVE` | **Yes** |
| Trailing completed-loss streak `>= 3` | `CONSECUTIVE_LOSSES_{n}` | **Yes** |
| Peak-to-trough giveback `>= 0.40` (`peak > 0`) | `DRAWDOWN_FROM_PEAK` | **Yes** |
| `IsTraderEligible` false after the above | `NO_LONGER_ELIGIBLE_{reason}` | **Yes** |

Net-zero is a loser (`<= 0`). Empty reconstructed book on an `ADMITTED` seat is net `0` → **fail-closed REMOVE**.

KEEP (stay `ADMITTED`) is only possible when `alreadyOnRoster` and:

1. not blocked / not size-pattern / demo-or-contest, **and**
2. completed XAU net `> 0`, **and**
3. consecutive losses `< 3`, **and**
4. drawdown-from-peak `< 40%` (or peak `== 0`, which `net<=0` already caught), **and**
5. `XauUsdOneToOneCopyPolicy.IsTraderEligible` still true (`XauNetPnl > 0`, n≥20, SHADOW/LIVE_CANDIDATE/LIVE).

That is not “leave losers on the roster.” It is “keep a still-green, still-eligible name.”

## 6. ADMIT / REMOVE / FLATTEN implication

- **ADMIT** = dest roster ON. Not a send license by itself (shadow still `AllowFixSend=false`; demo send is a later hop that re-reads `ADMITTED`).
- **REMOVE** = dest roster OFF (`REMOVED:<reason>`). Losers are **not** left seated. New shadow opens and new demo opens stop on the same 20 s cycle.
- **FLATTEN** = dest-only `FLATTEN_LOSS_CUT` close intents for known `copy:` opens. Never MT5 source. Demo FIX close-on-REMOVE is **not** wired (source-complete close is). Product flatten **intent** exists; product flatten **send** on REMOVE is residual, not absence of the roster verb.
