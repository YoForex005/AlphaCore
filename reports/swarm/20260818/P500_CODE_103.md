## Angle

Are the martingale and averaging **filters** in (or produced by) `TradeReconstructor` strong enough to cut the left tail of copied or would-be-copied XAU books — same-position grid / double-down / add-at-worse-price blow-ups — given live census 8463 accounts, Achiever scoring, Starwave deals-done scored 0, SHADOW-all-demo, dest real P&L 0, FIX LoggedOn, `REAL_COPY` false?

“Filter” here means a gate that **removes** that book from first-three, scoring input, or dest size. A boolean tag that still flows downstream is detection, not a cut.

---

## Verdict

**FAIL — no. Martingale and averaging filters in this file are not strong enough to cut the left tail, because they do not exist as filters.**

What the reconstructor actually does:

- **Averaging:** `ScaleIn` latches `WasAveragedDown` when a same-side add is **strictly worse** than the **pre-fill** entry VWAP (long `price < VWAP`, short `price > VWAP`). The flag is copied onto `ReconstructedTradeResult`. The trade is still completed, still XAU-eligible, still first-three eligible.
- **Martingale:** **absent.** Intra-position doubling is collapsed into one lifecycle (`MaxVolumeLots` grows). Classic recovery (0.01 + 0.02 + 0.04 + 0.08, close the basket) is one reconstructed trade, not a sequence the scorer can label `Martingale`.
- **Same-price grid:** `==` VWAP is not worse. Adds at the same level set `WasScaledIn` only. Averaging flag stays false.
- **Cancel dirt** is the only eligibility cut, and it is not a behavior cut.

Downstream (not this file; quoted so the FAIL is not a reconstructor-only nit):

- `BaselineScorer` martingale = **adjacent completed** XAU pair, prior `NetRealizedPnl < 0` **and** next `MaxVolumeLots > 1.25×`. Averaging = `trades.Any(t => t.WasAveragedDown)`. Risk **+35 / +20**. `RISK_BLOCKED` only if `risk >= 80` **or** `(Martingale ∧ MaxDrawdown > 0 ∧ NetPnl < 0)`. A **winning** recovered grid is often `Martingale=false`, `AveragingDown=true`, `risk=20`, and can land **`SHADOW`** (`quality >= 70 && risk < 40`).
- `RiskEngine` has `BlockMartingale` on a caller-supplied `MartingaleFlag`. **No** `AveragingDown` / `WasAveragedDown` field on `RiskEvaluationRequest`. Averaging is invisible to dest risk.
- `CopyTradingService` sizes dest from `trade.MaxVolumeLots` (the **basket** after adds), then passes `MartingaleFlag = score.Martingale` (inter-trade, not intra-position). `AllowFixSend` is hard-false on that path today.

Live census does **not** rescue the filters:

- 8463 source accounts can still run grids on the challenge side. This class reconstructs them as valid completed XAU.
- Achiever scoring can consume those reconstructions; Starwave **deals-done scored 0** means that broker’s left tail is **unscored**, therefore unfiltered by the scorer.
- SHADOW all demo + `destinationRealPnl` **0** + `REAL_COPY` **false** means dest left tail is cut by **not copying**, not by anything in `TradeReconstructor`.
- FIX **LoggedOn** is session state. Logon without a reconstruction reject is not a left-tail cut.

## Profit implication

- **Today:** dest P&L cannot improve or degrade from these flags. `REAL_COPY` is false, SHADOW is all demo, `destinationRealPnl` is 0. Reconstruction quality does not print dest edge.
- **If copy were enabled:** recovered grids look like high win-rate, high profit-factor XAU. `CompletedXauUsdTrades` will feed them into Achiever first-three / early score. Copy qty = `MaxVolumeLots` (the recovered basket). Apparent source profit is **not** dest edge — dest would be buying the **post-average size at entry VWAP of a closed historical book** (`CopyTradingService` uses `trade.EntryVwap` and `trade.OpenedAt`, then 15s expiry). That is stale-signal copy of bloated size, not a filter-selected edge.
- Starwave deals-done scored **0**: that broker contributes **no** scored XAU tape, so no reconstructed filter can create profit there.
- Hard-zero `Fees` inflates `NetRealizedPnl` vs true round-trip. Winners look cleaner than they are; that biases first-three quality **up**.

Do **not** treat Achiever scored winners that `WasAveragedDown` as a profit engine. The flag is informational.

## Lower-loss implication

- **Today:** dest left tail is cut by `REAL_COPY false` + `CanPromoteToLive => false` + copy-path `AllowFixSend = false`, **not** by this class.
- **If those locks were lifted:** this file would **not** reduce dest left-tail severity.
  - No reconstruction reject of averaging / intra-position doubling.
  - Same-price martingale / grid is not even tagged as averaged.
  - Inter-trade martingale is someone else’s 1.25× rule, and it misses the one-position recovery EA that dominates gold challenge books.
  - Averaging risk +20 never reaches `RISK_BLOCKED` alone; winning martingales can sit in SHADOW (`risk < 40`).
  - Dest risk has **no** averaging block; `MartingaleFlag` is the scorer bit, so a recovered intra-position grid copies at **max** lots until a later closed loss + 1.25× trip.
- 8463 source accounts: the left tail is the **challenge** book (grids that eventually stop out). Reconstruction will faithfully emit those as large `MaxVolumeLots` completed trades. Faithful reconstruction without a gate **concentrates** dest risk on the exact pattern that blows gold books.
- Honest loss-reduction available **without** enabling copy: keep `REAL_COPY` false; do **not** promote on first-three that include `WasAveragedDown` / `WasScaledIn`; do **not** size dest from `MaxVolumeLots` of an averaged lifecycle. Those cuts are **not implemented** in the assigned file.
