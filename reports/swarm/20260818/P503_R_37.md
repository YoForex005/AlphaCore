## 2. What “peak-to-trough” actually computes

```111:126:D:\Prop\src\Domain\Copy\CopyRosterEngine.cs
    public static (decimal peak, decimal drawdown) DrawdownFromPeak(IReadOnlyList<ReconstructedTradeResult> closed)
    {
        var equity = 0m;
        var peak = 0m;
        var maxDd = 0m;
        foreach (var t in closed)
        {
            equity += t.NetRealizedPnl;
            if (equity > peak)
                peak = equity;
            var dd = peak - equity;
            if (dd > maxDd)
                maxDd = dd;
        }
        return (peak, maxDd);
    }
```

`Decide` feeds this helper **completed XAU only**, oldest → newest:

```55:58:D:\Prop\src\Domain\Copy\CopyRosterEngine.cs
        var xau = completedXau
            .Where(t => t.Completed && t.IsXauUsd)
            .OrderBy(t => t.ClosedAt ?? t.OpenedAt)
            .ToList();
```

`IsXauUsd` is `CanonicalSymbol == "XAUUSD"` (ordinal ignore-case). Hop prefilters `ReconstructedTrades` with `CanonicalSymbol == "XAUUSD"` then `ToResult` copies that code, so the filter is live.

| Rule | Measured fact |
|---|---|
| Input | Completed XAU reconstructed `NetRealizedPnl` only |
| Start | equity=0, peak=0 (no starting balance, no challenge DD, no dest MTM) |
| Peak | running **high-water of closed-trade equity**, updated only when `equity > peak` (strict) |
| Trough | max `peak − equity` after any close (`maxDd`) |
| Ratio | **`maxDd / final peak`** vs 0.40 inclusive — **not** current `(peak − equity)/peak`, **not** A22 `max_dd / scale` |
| Peak=0 | check **does not fire** (never-green book). Rostered `net<=0` dies on `XAU_BOOK_TURNED_NEGATIVE` instead |
| Open gold | **ignored**. A −$10k live XAU ticket does not move this number until it closes |
| Recovered hole | `maxDd` is historical max. A book that started −700 then recovered to +300 still has `maxDd=700`, `peak=300`, ratio **2.33** → REMOVE if rostered |
| A22 scale | **different.** A22 `max_dd_frac` divides by `Max(Σ\|pnl\|, peak, eps)`. Roster divides by **final peak only** |

Intended give-back story (20 × +50, then −700):

| Step | Equity | Peak | maxDd | ratio |
|---|---:|---:|---:|---:|
| 20 × +50 | 1,000 | 1,000 | 0 | 0 |
| then −700 | 300 | 1,000 | **700** | **0.70** |

`0.70 >= 0.40` and `peak > 0` → **REMOVE**. Net is still **+$300**. Policy `IsTraderEligible` would still say `TRADER_ELIGIBLE` if the group is demo/contest (`XauNetPnl > 0`, n=21, SHADOW). **Eligibility is not a DD gate.**

Boundary: `399/1000 = 0.399` KEEP; `400/1000 = 0.40` REMOVE.

`P503_S03` T3 wrote `>` 40% and “current equity vs peak.” Product is **`>=`** and **max historical $ DD / final peak**. Slot 37 reports the code, not the design note.
