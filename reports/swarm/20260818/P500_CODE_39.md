## Lower-loss implication

**Protects capital by not sending. Does not cut losing source books out of SHADOW.**

- This POCO’s default-false flag + hosted `RealCopyEnabled=false` + no `35=D` builder = **risk to capital NONE** from this file (`SAFE_BY_ABSENCE` + explicit pin).
- It does **not** lower loss by filtering negative `netSourcePnl`. A losing-but-clean 3-trade book can still be `SHADOW` and still get `SHADOW_ONLY` intents.
- `RISK_BLOCKED` only fires for **martingale ∧ DD>0 ∧ NetPnl<0** (or risk≥80). A losing non-martingale book is not blocked.
- If an operator later treats SHADOW as a copy queue, **negative source trades will be in that queue**. Loss reduction vs live copy today is **do not send**, not dest-aware size-down.
- Flipping `CTrader:RealCopyExecutionEnabled` in the worker only logs a warning; it still cannot send. That is not a tested refuse on a live TRADE socket.
