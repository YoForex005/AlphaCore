Adjacent scoring law (the actual proof of the angle):

| Layer | What it does with negative source PnL |
|---|---|
| `ComputeFeatures` | `NetPnl = Σ NetRealizedPnl`. Negative is a legal number. |
| `Score` quality | `NetPnl > 0` is only a **+15 bonus**. Not a hard floor. |
| `FromBaseline` | `SHADOW` if `quality >= 70 && risk < 40`. **Does not test `NetPnl`.** Negative net + martingale + DD>0 → `RISK_BLOCKED`. Negative net **alone** is not a block. |
| Clean N≥3, SL used, no flags, `NetPnl <= 0` | `risk=0`, `behavior=100`, `quality=50+20=70` → **`SHADOW`**. |
| Persist | `state == SHADOW` then **every** completed XAU, including losers. Status `"SHADOW_ONLY"`. |
| Dashboard | `NetSourcePnl` is a **sum of all completed reconstructed trades** (any symbol). Sort key is `EarlyScore` desc. Overview `DestinationRealPnl` is constructor literal **0**. |

Algebra for a disciplined loser (N=3, SL on, no martingale/averaging/escalation, net ≤ 0, PF < 1.2):

```text
quality = 50
        +  0          // NetPnl > 0 bonus skipped
        +  0          // PF bonuses skipped
        + 0.20 * 100  // behavior
        - 0.25 * 0    // risk
        = 70.00  →  SHADOW
```

That is a **behavior/risk labeler**, not “only winners copy.”
