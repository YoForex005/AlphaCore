## 1. Official evidence (remeasured this slot)

Primary page fetched 2026-08-18: https://help.ctrader.com/fix/

### 1.1 Trade copiers are listed, then immediately downgraded

Quoted in full from “Typical application methods of FIX API in the industry” → **Trade copiers**:

> Systems that will automatically replicate trades on multiple trading accounts across multiple brokers or on the accounts of traders are connected to the copier. **However, we believe other Spotware APIs are more suitable for this.**

The same page applies the same “other Spotware APIs are more suitable” sentence to **custom trading interfaces**.

That is **not**:

- a Pepperstone / Spotware license for *this* lab to fire market orders;
- a claim that FIX copy of 8,463 MT5 challenge logins is +EV;
- a waiver of Architecture §41 / §68 / §70.

It is vendor prose that FIX *can* be used to replicate trades, plus an explicit preference for **other Spotware APIs** for copy.

### 1.2 What those “other APIs” actually are

Limitations page (https://help.ctrader.com/fix/limitations/ ), fetched this slot:

> FIX API serves two primary purposes: 1. Receive live market data 2. Perform trading operations

> with FIX API they will not be able to access cTrader account information such as current balance, leverage, margin and more.

> it does not support requests for historical market data.

That page points at **Open API** (https://openapi.ctrader.com/ / https://help.ctrader.com/open-api/) “to request market data, account information and additional functionality.”

Open API getting-started (fetched this slot) lists trading-oriented apps, a **demo-then-live** recommendation, and **rate limits**: 50 req/s non-historical, 5 req/s historical.

Open API terms (https://help.ctrader.com/open-api/terms-of-use/ , fetched this slot) grant a **limited, non-exclusive, non-assignable, non-transferable** API license “to develop, test and support your application.” Fair-use also says the application must **not** execute trading actions on behalf of a trader **without the trader’s explicit prior approval**. That is **not** a blank check to dump every Achiever / Starwave login onto one retail dest.

FIX cannot see dest **balance / leverage / margin**. `RiskLimits.MaxMarginUsage = 0.70` cannot be evaluated from FIX alone. Copying 8,463 source books onto one login without dest equity is how you blow the account *even if* a sender existed. That is exactly why Spotware prefers another API for copy.

### 1.3 Official protocol still has `35=D` — on TRADE only

https://help.ctrader.com/fix/specification/ defines New Order Single `MsgType(35)=D`:

| Tag | Field | Official note |
|---|---|---|
| 11 | `ClOrdID` | Client unique id |
| 55 | `Symbol` | **Long** — “Instrument identifiers are provided by Spotware” (not the string `XAUUSD`) |
| 54 | `Side` | `1` Buy / `2` Sell |
| 38 | `OrderQty` | Qty; max precision 0.01 |
| 40 | `OrdType` | `1` Market IOC, `2` Limit, `3` Stop |
| 57 | `TargetSubID` | Official examples use **`TRADE`** |

Official market-order example (RoE, not sent by this slot):

```text
8=FIX.4.4|…|35=D|56=CSERVER|57=TRADE|11=…|55=1|54=1|40=1|38=10000|…
```

A living copy system would also need Execution Report `8`, Order Status `H`, Mass Status `AF`, Positions `AN`/`AP`, Cancel `F`/`G`, Security List `x`/`y`. Official RoE is a **protocol**, not a copier.

Official header `TargetCompID` valid value is **`CSERVER`**. Product POCO default is `cServer` (UI-form spelling). This slot did not send either.
