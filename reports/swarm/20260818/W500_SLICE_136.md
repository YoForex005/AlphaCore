## No-loss implication

This class cannot hide an unsored account from the dashboard or from the scoring loop: it never joins `TraderScores` when writing or listing `Mt5Accounts`. Live ingest (`LiveIngestHostedService`) calls `ListLoginsAsync` and scores every returned login, so a missing `TraderScore` row is a **pending write**, not a dropped account. `PersistDemoShadowAsync` only emits shadow copy intents when `state == TraderState.SHADOW`; unsored accounts never reach copy/LIVE through this store. No live capital is at risk from a “hide if no score” filter in `EfTradingStore` — that filter is absent.

**Not claimed:** overview state tallies include unsored logins (they do not; that is `EfDashboardQueries.GetOverviewAsync`, slot-out-of-scope). Optional `state=` filter on `/traders` will exclude `INSUFFICIENT_DATA` when the operator asks for another state — that is an explicit filter, not a default hide.
