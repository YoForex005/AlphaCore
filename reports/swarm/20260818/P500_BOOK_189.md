## 2. Why `DealsInserted=91966` is not `Scored>0`

### 2.1 Hosted pipeline scores brokers **after** all deals, Achiever first

`LiveMt5Registration.CreateConnectors` returns `{ ACHIEVER, STARWAVEFX }` in that order (`LiveMt5Registration.cs` L49). DI registers that array as singletons (`DependencyInjection.cs` L47–50). `BrokerRegistry` stores them in a `Dictionary` (`BrokerRegistry.cs` L9–21). On net8.0, `Dictionary` preserves insertion order, so `All()` is Achiever then Starwave.

Starwave `ProxyEnabled` is hardcoded `false` (L45). Do not reuse the Achiever HTTP hop.

`LiveIngestHostedService.ExecuteAsync` then runs **three sequential loops** over `registry.All()`:

1. catalog (`SyncCatalogAsync`) → `phase=catalog-done`
2. deals (`SyncBrokerAsync` → `st.DealsInserted = deals`, `phase=deals-done`)
3. scoring (`ListLoginsWithDealsAsync` → `RebuildTraderAsync`, then `st.Scored`)

Window is `UtcNow.AddDays(-90)` (L37). The mid-scoring pin is exactly this stall: Achiever is inside loop 3; Starwave is still labeled `deals-done` with `Scored=0`. That is **pipeline order**, not “Starwave has no XAU” and not “Starwave quality is zero.”

`BrokerLiveStatus.Scored` is an `int` defaulting to **0** (`LiveRuntimeStatus.cs` L14) and is **only assigned inside loop 3**. Until Starwave enters that loop, `Scored` stays **0**.

**Slot-189 discriminator (do not misread a lagging counter):** `st.Phase = "scoring"` is written **before** the login loop (`LiveIngestHostedService.cs` L107). `st.Scored` is **not** written until `scored % 25 == 0` (L115–118), then again at the end (L122). So `scored=0` *alone* could theoretically mean “0–24 logins in, counter not flushed.” **`phase=deals-done` rules that out.** The pin is a **queue stall**, not a stale every-25 counter.

**Second discriminator:** `st.Scored` increments once per login in `ListLoginsWithDealsAsync`, **including 0-XAU logins**. It is not `overview.xauTraders` (`CompletedXauTrades > 0`). After Starwave finishes loop 3, ingest `scored` can be large while the XAU leaderboard barely moves.
