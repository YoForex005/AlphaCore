## Angle

Does first-3 / `earlyScore` **95.5** on demo group `yo-2step` measure **future destination** (cTrader / Pepperstone) PnL?

The trading truth: a three-trade demo quality number is **source-book** history. Destination PnL is what the dest venue actually books after spread, dest commission, dest swap, copy delay, and dest fill. Those are not the same series. This slot asks whether `ShadowCopyEngine` — the only domain type that even mentions dest quotes — turns that 95.5 into a dest-PnL forecast.

## Verdict

1. **No first-3.** Grep of `D:\Prop\src\Domain\Shadow` for `earlyScore`, `EarlyScore`, `first-3`, `First3`, `destinationRealPnl`, `REAL_COPY`, `yo-2step`, `95.5` returned **zero matches**.

4. **`ShadowPosition` is a dead record.** It has `UnrealizedPnl` / `RealizedPnl` fields, but **no method constructs, updates, or returns** a `ShadowPosition`. Those decimals are never written by this engine.

High quality (≥70, risk <40) maps to `SHADOW`, not dest money. `AfterHighEarlyScore() => SHADOW`. `CanPromoteToLive(_) => false`. A 95.5 on demo `yo-2step` is a source-quality tile.

## What the file actually is

Three public types, no I/O, no scoring, no broker, no FIX:

1. `ShadowFill` — order id, price, qty, timestamp, spread, quote age, source-vs-shadow slippage.
2. `ShadowPosition` — broker/login/trade id, side, qty, entry/exit, unrealized/realized, open flag. **Unused by the engine.**
3. `ShadowCopyEngine` — taker-touch calculator.

Path:

| Method | Price used | Extra |
|---|---|---|
| `SimulateEntry` | Long = Ask, Short = Bid | If `modeledDelay > 250ms`, add `±0.05` points (`DefaultLatencySlippagePoints`). Slippage vs **source** print. Always returns a fill. |
| `SimulateExit` | Long close = Bid, Short close = Ask | Same always-fill; no delay overlay. |
| `MarkToMarket` | Same touch as exit | `(px − entry) × sign × qty`. No costs. No horizon. |

Callers (not this file, cited only to bound profit): `CopyTradingService` and `EfTradingStore.PersistDemoShadowAsync` pass **80 ms** delay, so the 0.05 overlay **does not apply**. Product path is dest touch ± 0, persisted as a `ShadowOrder` row, not dest realized PnL.

`yo-2step` is an MT5 group map (`demo\yo-2step` / `contest\yo-2step`) in architecture docs. This compilation unit never sees group names.

    public ShadowFill SimulateEntry(
        string shadowOrderId,
        TradeDirection direction,
        decimal quantity,
        decimal sourcePrice,
        DestinationQuote quote,
        DateTimeOffset now,
        TimeSpan modeledDelay)
    {
        var useAsk = direction == TradeDirection.Long;
        var raw = useAsk ? quote.Ask : quote.Bid;
        var adverse = direction == TradeDirection.Long ? DefaultLatencySlippagePoints : -DefaultLatencySlippagePoints;
        if (modeledDelay > TimeSpan.FromMilliseconds(250))
            raw += adverse;

        var slippage = direction == TradeDirection.Long ? raw - sourcePrice : sourcePrice - raw;
        return new ShadowFill
        {
            ShadowOrderId = shadowOrderId,
            Price = raw,
            Quantity = quantity,
            FilledAt = now,
            Spread = quote.Ask - quote.Bid,
            QuoteAge = now - quote.ReceivedAt,
            SourceVsShadowSlippage = slippage
        };
    }

    public decimal MarkToMarket(TradeDirection direction, decimal qty, decimal entry, DestinationQuote quote)
    {
        var px = direction == TradeDirection.Long ? quote.Bid : quote.Ask;
        var sign = direction == TradeDirection.Long ? 1m : -1m;
        return (px - entry) * sign * qty;
    }

## Profit implication

**No dest profit can be inferred from 95.5.** A demo `yo-2step` Achiever book that prints `EarlyQualityScore = 95.5` after three completed XAU closes is a **source** quality blend (base 50 + net-positive + PF steps + 20% of behavior − 25% of risk). It is not Pepperstone / cTrader expectancy.

If operators treat 95.5 as “this trader will make dest money”:

- They would size or promote on **N=3 demo** path-dependence.
- This engine would only invent a paper fill at dest bid/ask (80 ms path: **no** 0.05 overlay).
- Dashboard “Shadow P&L” is `SUM(SourceVsShadowSlippage)`, a **price-delta**, not dest net after commission/swap/fees.
- `destinationRealPnl` stays **0** because nothing books dest realized. Starwave deals-done scored 0 cannot even produce the first-3 tile; Achiever demo SHADOW can produce 95.5 and still contribute **$0 dest**.

Profit claim from this file: **none.** Simulated touch ≠ dest edge.
