**FAIL — NO. Sub-3-minute gold scalps would not survive FIX latency plus destination spread as a copy-profit strategy.**

Four independent reasons, all measured in the assigned file or in the hop/spread law it sits on:

1. **There is no dest fill tape to survive on.** The assigned file forces `REAL_COPY_EXECUTION_ENABLED` **false**, states live `35=D` NewOrderSingle is **OFF** because the method **does not exist**, and pins copy intents to **SHADOW-only** (“That is how this process avoids taking a live loss”). A live gold scalp cannot be shown to “survive” when nothing is sent and dest PnL is a hard zero.
2. **A 180 s hold already sits inside the reject / catch-up window.** Architecture §63: if TRADE is down for **3 minutes** while 20 source opens print, reconnect must emit **0** `NewOrderSingle`. Lab OPEN cap is `MaxSourceSignalAge = 15 s` (**8.3 %** of the hold). `docs/risk.md` copy window is **100–2000 ms**. The FIX type behind the file’s LoggedOn is a **20 s** cold TLS+Logon probe that **disposes the socket** after one `35=A` read — **11 %** of the hold, **10×** the 2 s copy-delay ceiling, and able to blow the 15 s signal-age cap before a fill is even attempted.
3. **Dest spread + modeled lag eat the typical scalp target.** Shadow fills dest touch (long = ask / short = bid) and adds **0.05** XAU points when `modeledDelay > 250 ms`. `MaxAllowedSpread = 2.0` still **allows** a 2-point dest book. `MaxPriceMove = 3.0` still **allows** a 3-point mid move. `MaxSlippage = 1.5` exists on `RiskLimits` and is **never read** in `Evaluate`. A sub-3-minute gold scalp that aims for tenths-to-low-single-digit points is dead at dest half-spread + lag alone, even before Achiever’s HTTP proxy hop.
4. **Hold time is recorded and then ignored.** `FeatureSnapshot.AverageHoldSeconds` is computed; `FromBaseline` never rejects holds &lt; 180 s. A 90 s gold scalp can still land `SHADOW` if quality ≥70 and risk &lt;40. Starwave **deals-done scored 0** means those **1948** (file) logins contributed **no** hold-time book this run. There is no measured “scalps are long enough” sample.

FIX QUOTE+TRADE **LoggedOn** in the assigned file is session-up after tag **553 = integer account id**, not fill quality and not a dest quote tape. Logon + `35=D` OFF is **not** a measured source-to-fill that gold scalps can “survive.”
