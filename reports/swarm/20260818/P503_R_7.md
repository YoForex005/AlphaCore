## 2. What “peak-to-trough” actually computes

```113:128:D:\Prop\src\Domain\Copy\CopyRosterEngine.cs
    public static (decimal peak, decimal drawdown) DrawdownFromPeak(IReadOnlyList<ReconstructedTradeResult> closed)
    {
        var equity = 0m;
        var peak = 0m;
        var maxDd = 0m;
        foreach (var t in closed)
        {
            equity += t.NetRealizedPnl;
            if (equity > peak)
                peak = equity;
            var dd = peak - equity;
            if (dd > maxDd)
                maxDd = dd;
        }
        return (peak, maxDd);
    }
```

| Rule | Measured fact |
|---|---|
| Input | Completed XAU only (`Completed && IsXauUsd`), ordered by `ClosedAt ?? OpenedAt` |
| Start | equity=0, peak=0 (no starting balance, no challenge DD, no dest MTM) |
| Peak | running **high-water of closed-trade equity**, not Σ\|pnl\| |
| Trough | max `peak − equity` after any close |
| Ratio | `maxDd / peak` vs **0.40 inclusive** |
| Peak=0 | check **does not fire** (all-loss-from-zero). Rostered net≤0 falls through to `XAU_BOOK_TURNED_NEGATIVE` instead |
| Open gold | **ignored**. A −$10k live XAU position does not move this number until it closes |
| A22 scale | **different.** A22 `max_dd_frac` divides by `Max(Σ\|pnl\|, peak, eps)`. Roster divides by **peak only**. Same tape, larger roster ratio |

Same walking sum lives in `BaselineScorer.ComputeFeatures` (`MaxDrawdown` dollars). That scorer **does not remove**. It adds **+10 risk** only if `MaxDrawdown > GrossProfit` **and** `GrossProfit > 0`. `TraderStateMachine` only `RISK_BLOCKED`s on `risk≥80` or `(Martingale && MaxDrawdown>0 && NetPnl<0)`.

`RiskEngine.MaxPortfolioDrawdown = 3000` is dest **dollars**, hardcoded `PortfolioDrawdown=0` on the copy hop. It is not source XAU %.
