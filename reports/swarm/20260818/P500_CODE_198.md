## Angle

Is a **+$100** prop-challenge / demo reconstructed PnL (typical Achiever `demo\*` / first-3 XAU print) a **copyable destination edge** after cTrader / Pepperstone venue costs (spread, dest commission, dest swap, copy latency, size conversion)?

This host is the live **catalog → deals (−90d) → score** loop. If it treated +$100 source tape as dest-edge, it would be a false-profit path. Architecture: three trades are not skill; dest costs/slippage must be **measured** before live copy.

## Verdict

**CONFIRMED_NOT_EDGE.** After reading all 141 lines:

1. The host never sees dollars. It catalogs **all** manager groups/accounts (caller **8463**), ingest deals for **connected** brokers only, then scores **only** `ListLoginsWithDealsAsync`. There is **no** dest quote, dest commission, dest spread, dest slippage haircut, min-edge floor, or `destinationRealPnl` write.
2. A +$100 challenge close is **source-book residual** (Manager `Profit` + source commission/swap; reconstructor `Fees` hardcoded **0**). Destination XAU round-trip on even **0.10–1.00 lot** is the same order of magnitude as $100. That residual is **not** Pepperstone cash.
3. Starwave **deals-done scored 0** is this file’s third loop with an **empty** deals-login set (or `scored` never left 0). It is **not** a hidden +$100 dest book.
4. Adjacent scorer (this host **does** call it) still does `if (features.NetPnl > 0) quality += 15`. +$100 **can** inflate `EarlyQualityScore` toward **SHADOW**. That is a **ranking leak**, not dest profit. `FromBaseline` max good state is SHADOW; `CanPromoteToLive => false`.
5. Dashboard dest tile remains constructor **`0`**. Matches live pin `destinationRealPnl 0`. That zero is **uncomputed dest book**, not “+$100 minus venue costs = 0.”

Honesty: dest PnL 0 is **allowed** while `REAL_COPY` is false. The residual failure is **edge hygiene on the score path this host drives** — any deals-bearing Achiever challenge book with source net +$100 still ranks as quality.

This is **not** an empty PASS.
