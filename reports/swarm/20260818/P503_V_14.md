## 3. Loser × roster matrix (what “not left” means)

`onRoster` is a **string status**, not a sticky latch. After REMOVE the same row is reused; the next Decide sees `alreadyOnRoster=false`.

| After next `TickRosterAsync` | Still `ADMITTED`? | Re-ADMIT next 20 s? |
|---|---|---|
| Net completed XAU ≤ 0 | **No** (`REMOVED:XAU_BOOK_TURNED_NEGATIVE`) | **No** (policy `XAU_BOOK_NOT_PROFITABLE`) |
| `RISK_BLOCKED` / `DISQUALIFIED` / `PAUSED` | **No** (`REMOVED:STATE_*`) | **No** while state holds |
| Size pattern | **No** (`REMOVED:SIZE_PATTERN`) | **No** while flags hold |
| Real group | **No** (`REMOVED:NOT_DEMO_OR_CONTEST_GROUP`) | **No** |
| On-roster streak ≥ 3, book still green | **No** this tick | **Yes** — ADMIT skips streak |
| On-roster DD ≥ 40% of peak, book still green | **No** this tick | **Yes** — ADMIT skips DD |
| Never eligible (WATCH / n<20 / red) | never seated (`Keep` / `NOT_YET_*`) | **No** |

Assigned question is **losers not left on the roster**. Net-red, blocked, patterned, and real-group names are **off** after the tick and stay off. That is PASS.

Still-green give-back (DD or streak) is **removed then re-admitted**. That is oscillation, not “left from the REMOVE tick.” It is a residual, not the missing-remove FAIL.
