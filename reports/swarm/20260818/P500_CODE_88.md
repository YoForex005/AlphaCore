## Verdict

## Adjacent formula (why source +$100 already is not dest-net)

This class does not recompute PnL; it **sums** `ReconstructedTrade.NetRealizedPnl`. Reconstruction (`TradeReconstructor`) sets:

```text
NetRealizedPnl = GrossRealizedPnl + Commission + Swap + fees
fees = 0m
```

`Commission` / `Swap` are **source MT5 deal** accumulators, not cTrader venue charges. Dest spread (seed book 2399.45 / 2399.85 = **$0.40** XAU touch, or whatever live Pepperstone quote is) is **never** applied to `NetSourcePnl`. Copy slippage is stored on `ShadowOrder` and, on the overview, summed as **slippage**, not as “challenge PnL after dest costs.” Per-trader shadow is hardcoded 0, so the operator comparing two +$100 challenge accounts cannot even see that slippage.

Architecture law the dashboard is violating as an *edge meter*:

```text
The target is not: Who made the most money in their first 3 trades?
The target is: positive future execution-venue-net P&L while remaining inside risk limits.
```

```text
Do not include: final challenge result, future balance, eventual pass/fail.
```

A +$100 challenge print is **challenge-tape source net**. It is the forbidden proxy.

## Profit implication

**No destination profit is proven by a +$100 challenge print, and this query class cannot measure one.**

- `destinationRealPnl = 0` is **uncomputed**, not “the dest book netted the +$100 down to zero after costs.”
- Ranking 8463 Achiever/Starwave rows by `EarlyScore` (L128) while painting `NetSourcePnl` invites the operator to treat a **+$100 challenge pass** as copyable gold. That is the opposite of §3.
- After venue costs, a +$100 source stack on XAU scalps is often **inside one day’s dest spread + commission + copy slip**. This class never subtracts those, so it cannot claim residual edge.
- Starwave deals-done scored **0** means ~1948 catalog accounts contribute **no** scored first-3 — and still no dest-net. Achiever scoring does not fill that hole.
- Enabling `REAL_COPY` later to “realize” the +$100 would send size against a dest book this dashboard has **never** rolled up (`XauGross`/`XauNet`/`DailyPnl` all literal 0).
