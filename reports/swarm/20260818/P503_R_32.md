### 1.2 Predicate is unguarded (all actions)


Measured properties:

| Property | Measured |
|---|---|
| Compare | `<=` — fires at **exactly** `-$500` |
| Action filter | **None.** Unlike quote / spread / size / martingale (all `&& IsIncreasing`), this line has **no** `IsIncreasing` / `IsReducing` guard |

`IsIncreasing` = `OpenExposure | IncreaseExposure`. `IsReducing` = `ReduceExposure | CloseExposure`. The reducing branch (`RISK_REDUCTION` Approve, L152–161) is **unreachable** once `TraderRealizedLoss <= -500`.

That is the A71 §14 defect: “`TraderRealizedLoss`, daily PnL, portfolio DD apply to **all** classes (lines 117–124). **Would freeze exits on a losing day.** CLOSE family must pass.” Same three book-loss reasons are the **3/19** that **increase** trapped dest loss if a sender later existed (P500_BOOK_101).

`PauseTrader` is a decision vocabulary value only (`RiskDecisionOutcome.cs` L8). Product writers of `TraderState.PAUSED` under `src/` = **0**. Policy *would* honor a PAUSED score (`IsTraderEligible` → `TRADER_BLOCKED_PAUSED` for **every** action, including close). Mapping this outcome onto that state would **REMOVE + freeze flatten**. Do not do that.

| Sum of that trader’s completed XAU (the hop already has `XauNetPnl`) | **No.** Snapshot computes `xau.Where(t => t.Completed).Sum(t => t.NetRealizedPnl)` at L204 and **does not pass it** |

So the `$500` line, on the only product caller, is “has **this one still-open source ticket** already realized `<= -$500` (partials + swap)?” — not “has **this copied trader’s dest book** lost $500?”

A trader with ten open tickets of −$400 each (source) **never** trips the cap. A trader whose dest already lost $5,000 **never** trips it, because dest PnL is not an input. A later ticket from the same login is evaluated with **that ticket’s** (usually ~0) PnL — there is **no running per-login bucket**.

Three clocks exist. None is a market tick into `MaxLossPerTrader`.
