## 2. Recalculation: 95.50 is a unique signature

Write the blend as

```text
quality = 50 + N_bonus + PF_bonus + 0.20·B − 0.25·R
N_bonus  = 15 if features.NetPnl > 0 else 0
PF_bonus = 15 if PF ≥ 1.8; 10 if 1.2 ≤ PF < 1.8; else 0
B ∈ [0, 100], R ∈ [0, 100]
max(0.20·B − 0.25·R) = 20.00    (B=100, R=0)
```

### 2.1 95.50 requires XAU net > 0

| XAU `features.NetPnl` | PF possible | Max quality |
|---|---|---:|
| `> 0` and `PF ≥ 1.8` | yes | **100.00** |
| `> 0` and `1.2 ≤ PF < 1.8` | yes | **95.00** (`75 + 20`) — **cannot hit 95.50** |
| `> 0` and `PF < 1.2` | yes | **85.00** |
| `≤ 0` | `PF = GP/GL ≤ 1` (or 0 if both zero) | **70.00** (`50 + 20`) |

So **95.50 is impossible on a losing or flat XAU book.** The +15 net flag is load-bearing. I9 of A22 even forbids ranking by raw net; the stub still uses the sign as a bonus, not a veto — and still cannot print 95.50 without that bonus.

### 2.2 On the implemented flag grid, 95.50 is exactly (B, R) = (90, 10)

Need `0.20·B − 0.25·R = 15.50` after full bonuses (`50+15+10+5 = 80`).

Typical flag pair that hits it:

```text
SlUseRate = 0  →  risk += 10, behavior −= 10
no martingale / averaging / lot-escalation / lotCv / lossCv / DD>GP

B = 90, R = 10
0.20·90 − 0.25·10 = 18.00 − 2.50 = 15.50
quality = 50 + 15 + 10 + 5 + 15.50 = 95.50
```

Nearby legal scores on the same bonus set (so 95.50 is not “any good book”):

| Book shape | B | R | Quality |
|---|---:|---:|---:|
| Clean winners, **SL used** (`SlUseRate ≥ 0.5`) | 100 | 0 | **100.00** |
| Clean winners, SL in `[0.3, 0.5)` | 90 | 0 | **98.00** |
| Clean winners, **no SL** (the 95.50 identity) | 90 | 10 | **95.50** |
| No SL + `LotCv ∈ (0.4, 0.5]` | 80 | 10 | **93.50** |
| Mild martingale only, SL used, net > 0, PF ≥ 1.8 | 70 | 35 | **86.25** (C32 measured **85.25** with SL on the 1.26× tape) |
| Losing martingale (demo 10002) | 50 | 70 | **42.50** → `RISK_BLOCKED` |

95.50 therefore means: **≥3 completed XAU, XAU net > 0, PF ≥ 1.8, no size-up flags, SL unused.** It does **not** mean “this login’s painted P&L is +95.50,” and it does **not** mean “destination gold after spread is positive.”

A22 `baseline.v1` would also subtract `U(3)=18` and cap a theoretically perfect first-3 book at **82**. The stub printing **95.50** is *more optimistic than spec* and still is not dest PnL.
