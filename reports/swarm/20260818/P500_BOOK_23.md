## 1. What `TradeReconstructor` actually does

It is a **netting book per `PositionId`**, not a basket / grid classifier.

```24:57:D:\Prop\src\Domain\Reconstruction\TradeReconstructor.cs
    public IReadOnlyList<ReconstructedTradeResult> Reconstruct(
        string brokerId,
        long login,
        IReadOnlyList<NormalizedDeal> deals)
    {
        // broker + login filter; dirtyPositions = BuyCanceled|SellCanceled
        var trading = scoped.Where(d => d.IsTradingDeal)
            .OrderBy(d => d.Time).ThenBy(d => d.DealTicket).ToList();

        foreach (var group in trading.GroupBy(d => d.PositionId))
        {
            var rows = ReconstructPosition(brokerId, login, group.Key, group.ToList());
            // canceled only flips EligibleForFirstThree — not a grid/risk dirty
            results.AddRange(rows);
        }
        return results.OrderBy(t => t.OpenedAt).ThenBy(t => t.PositionId).ToList();
    }
```

Same-second entries **sort together** (`Time` then `DealTicket`) and then **split** on `PositionId`. Sharing a timestamp does not merge books.

        public void ScaleIn(NormalizedDeal deal, decimal lots)
        {
            // Averaging down: add to a long after price fell, or to a short after price rose.
            var worse = Direction == TradeDirection.Long
                ? deal.Price < EntryVwap
                : deal.Price > EntryVwap;
