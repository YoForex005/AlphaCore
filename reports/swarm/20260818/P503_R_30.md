## 1. Assigned file — what the policy actually does

The type comment is explicit: live copy selects traders with a measured XAU edge, then copies **next** events 1:1. It does **not** wait for a ticket to be profitable (lookahead). Close is copied when the **source** closes.

```57:67:D:\Prop\src\Domain\Copy\XauUsdOneToOneCopyPolicy.cs
/// <summary>
/// Live copy selects <b>traders</b> with a measured XAUUSD edge, then copies their
/// next XAUUSD events 1:1 (lots, SL/TP, side). It does not wait until a ticket
/// is profitable — that is lookahead and cannot be traded live.
/// Close is copied when the source closes, not at a predicted time.
/// </summary>
public sealed class XauUsdOneToOneCopyPolicy
{
    public const int MinCompletedXauTrades = 20;
    public const decimal AllocationFactor = 1m;
```

There are exactly two public behaviors: `IsTraderEligible` and `Evaluate`. Neither mutates a roster.

### 1.1 ADMIT gate — `XauNetPnl <= 0` is a hard reject

```73:115:D:\Prop\src\Domain\Copy\XauUsdOneToOneCopyPolicy.cs
    public bool IsTraderEligible(CopyTraderSnapshot trader, out string reason)
    {
        if (trader.State is TraderState.RISK_BLOCKED or TraderState.DISQUALIFIED or TraderState.PAUSED)
        {
            reason = "TRADER_BLOCKED_" + trader.State;
            return false;
        }

        if (trader.State is TraderState.INSUFFICIENT_DATA or TraderState.EARLY_SCORE or TraderState.WATCH)
        {
            reason = "TRADER_NOT_SHADOW_YET";
            return false;
        }

        if (trader.Martingale || trader.AveragingDown || trader.LotEscalation)
        {
            reason = "TRADER_SIZE_PATTERN_BLOCK";
            return false;
        }

        if (trader.CompletedXauTrades < MinCompletedXauTrades)
        {
            reason = "NEED_MORE_XAU_HISTORY";
            return false;
        }

        if (trader.XauNetPnl <= 0)
        {
            reason = "XAU_BOOK_NOT_PROFITABLE";
            return false;
        }
        // demo\ / contest\ prefix reject …
        reason = "TRADER_ELIGIBLE";
        return true;
    }
```

`XauNetPnl <= 0` covers **zero and negative**. A book that was +400 at admit and is later −10 fails the same predicate as a name that never printed a profit. That is **not** “auto-remove after admit.” It is **re-scoring the same snapshot field**. The policy does not know whether the trader was previously eligible.

### 1.2 `Evaluate` re-applies the gate to every action, including close

```117:120:D:\Prop\src\Domain\Copy\XauUsdOneToOneCopyPolicy.cs
    public CopyInstruction Evaluate(CopyTraderSnapshot trader, CopySignal signal)
    {
        if (!IsTraderEligible(trader, out var traderReason))
            return Reject(traderReason);
```

`Reject` is `{ Accept = false, Reason = reason }` (L188–189). No `Action`, no dest qty, no flatten flag.

Consequence if an admitted trader’s completed XAU book later goes ≤ 0:

| Signal | `Evaluate` result |
|---|---|
| `OpenExposure` / `IncreaseExposure` / `ReduceExposure` | `Accept=false`, `XAU_BOOK_NOT_PROFITABLE` |
| `CloseExposure` (source just closed) | **Same reject** — eligibility is checked **before** action dispatch |
| Any dest-only unwind | **Impossible** — no such signal type is generated here |

The unit lock is the reject only. There is no “was eligible, now flatten” fact on this type:


`Close_of_open_book_is_one_to_one` (L125–136) uses `GoodTrader()` with `XauNetPnl = 400m`. A later-negative close is **untested** on the policy and would **fail** `IsTraderEligible` first.

Grep of `XauUsdOneToOneCopyPolicy.cs` for `Remove`, `Flatten`, `Roster`, `alreadyOnRoster`, `auto-remove`: **0**.

## 3. Live hop — skip trader, do not flatten dest

`CopyTradingService.GenerateShadowIntentsAsync` is the only production consumer of the policy. Snapshot `XauNetPnl` is recomputed every tick from completed reconstructed XAU:

```110:121:D:\Prop\src\Infrastructure\Copy\CopyTradingService.cs

            {
                State = score.CurrentState,
                CompletedXauTrades = score.CompletedXauTrades,
                XauNetPnl = xau.Where(t => t.Completed).Sum(t => t.NetRealizedPnl),
                Martingale = score.Martingale,
                AveragingDown = score.AveragingDown,
                LotEscalation = score.LotEscalation,
                GroupName = account?.GroupName
            };
            if (!_policy.IsTraderEligible(snapshot, out _))

```

`continue` is the **entire trader**. Effects after a previously eligible name prints a completed-XAU book ≤ 0:

| After post-admit `XauNetPnl <= 0` | Happens? |
|---|---|
| New `OpenExposure` for still-open source tickets | **No** |
| Auto dest flatten / `CloseExposure` because eligibility died | **No** — close loop is **below** this `continue` |
| Source-close still mirrored | **No** (same `continue`; even if reached, `Evaluate` would `Reject`) |
| Delete prior `CopyIntent` / `ShadowOrder` | **No** writer |
| `CopyRosterEngine.Decide(..., alreadyOnRoster: true)` | **Never called** |
| FIX dest flatten / `35=D` | **No** (`NewOrderSingleImplemented = false`; persist `AllowFixSend = false`) |

Hosted poll (20 s) only creates shadow intents:
