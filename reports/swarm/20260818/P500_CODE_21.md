## Why copy-all loses (counterfactual, given dominate-`RISK_BLOCKED`)

1. **Label meaning.** `RISK_BLOCKED` is the scorer’s “severe / losing-martingale” bucket. If that bucket dominates the scored Achiever book, the **median copied tape is a loser**.
2. **No state gate in this engine.** Copy-all never asks Evaluate “is this `RISK_BLOCKED`?” There is no field to ask with.
3. **Flags are spoofable / omitted.** Without a faithful `MartingaleFlag` from the score row, `MARTINGALE_BLOCK` never fires.
4. **Caps are after-the-fact and exit-hostile.** First N opens (up to 20 positions / 20 lots gross / 5 lots each) can fill. Then −$500 / −$2,000 / $3,000 trip **and also reject closes**. A book of cloned martingales that cannot flatten is a loss amplifier.
5. **`ReduceSize` on `MAX_XAU_NET` returns qty `0`** (Reject helper). Not a clipped smaller copy. First-to-cap still already on.
6. **Starwave 0 scored** does not save Achiever. Copy-all-scored is the Achiever scored set, which is the dominate-`RISK_BLOCKED` set in the caller pin.

This is **not** measured dest P&amp;L (dest is 0). It is the only honest reading of cloning a `RISK_BLOCKED`-majority book through an engine that cannot see the label.
