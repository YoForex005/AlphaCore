## Angle

Does this dashboard treat a **+$100 demo / prop-challenge** reconstructed PnL as a tradable edge after **destination (cTrader) venue costs** — dest spread, dest commission, dest swap, source-vs-dest slippage, copy delay?

Trading truth: **it is not an edge.** Challenge/demo `NetRealizedPnl` is **source-book** economics (often subsidized or differently commissioned). Destination XAUUSD costs routinely consume a low-three-digit dollar residual on a few lots. A +$100 first-three / challenge print is paper on the Achiever tape, not Pepperstone/cTrader expectancy.

This slot answers only what **this query layer** does with that number.

## Verdict

**FAIL — NOT_EDGE.** After reading all 217 lines:

1. `GetTradersAsync` walks **every** `Mt5Accounts` row (8463 live pin) and maps completed reconstructed `Sum(NetRealizedPnl)` into `NetSourcePnl`. No dest spread, dest commission, dest swap, dest fee, or slippage overlay. A +$100 challenge book appears as **+$100**.
2. `GetOverviewAsync` writes `DestinationRealPnl`, `XauGross`, and `XauNet` as **literal `0`**. That is the live pin `destinationRealPnl 0`. It is **uncomputed dest book**, not a cost-adjusted rollup of challenge PnL.
3. Overview “Shadow P&L” is `SUM(shadow_orders.SourceVsShadowSlippage)`, a **source-vs-shadow slippage tape**, not dest realized/unrealized net.
4. Per-trader `ShadowPnl` is a **third literal `0`**.
5. `GetTraderDetailAsync` reprints each trade’s source `NetRealizedPnl` (first-three XAU flagged only). Still no dest cost column.
6. `GetRiskAsync` hardcodes `DailyPnl`, `Drawdown`, `XauLong`, `XauShort`, `XauNet` to **0**. Dest cost / dest drawdown are invisible.
7. `GetFixSessionsAsync` hardcodes `ExecutionEnabled = false`. FIX **LoggedOn** can paint quote/trade healthy while dest fills (and dest costs) cannot exist.
8. Last overview flag is `_runtime.RealCopyEnabled` (live pin **false**). This file cannot flip it and cannot send.

Honesty: dest tile `0` is **allowed** while `REAL_COPY` is false and SHADOW is all demo. The failure is **edge hygiene** — source +$100 is still the only money number operators see on the trader grid, and it is **not** haircut for venue costs.

This is **not** an empty PASS.
