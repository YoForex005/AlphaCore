## Angle

Are the martingale and averaging **filters** in (or produced by) `TradeReconstructor` strong enough to cut the left tail of gold challenge books — same-position grid / double-down / add-at-worse-price blow-ups — given 8463 live accounts, Achiever scoring, Starwave deals-done scored 0, SHADOW-all-demo, dest real P&L 0, FIX LoggedOn, `REAL_COPY` false?

Left tail here = dest (or would-be dest) losses concentrated on recovered-then-blown averaging/martingale EAs. Cutting it requires removing those books from early-score eligibility and/or refusing to size dest from the **post-add basket**.

---

## Verdict

**FAIL — not strong enough, because the assigned file does not filter.**

What this reconstructor actually does:

1. **Averaging is a latch, not a gate.** Long add below pre-fill VWAP, or short add above, sets `WasAveragedDown = true` and it stays latched. The trade is still completed, still XAU-eligible, still first-three eligible, still returned from `Reconstruct`.
2. **Martingale is absent.** There is no identifier, no intra-position 2×/4× detector, no sequential-after-loss flag. Classic recovery (`0.01 + 0.02 + 0.04 + 0.08`, then close the basket) collapses to **one** lifecycle whose `MaxVolumeLots` is the peak remaining size. Downstream `BaselineScorer` only looks at **adjacent completed** trades, so that one recovered basket is invisible as `Martingale`.
3. **Same-price grid is not even averaging.** `worse` is a **strict** inequality vs VWAP. Adds at the current VWAP set `WasScaledIn` only. Equal-step martingale that fills at the running mean stays `WasAveragedDown = false`.
4. **Hedging-mode new `PositionId`s never average.** Each ticket `Start()`s a fresh `OpenTrade`. Grid EAs that open a new hedge ticket per add never hit `ScaleIn`, so both flags stay false on each row.
5. **The only eligibility cut is cancel dirt**, which is a data-quality rule, not a behavior rule.

Downstream (read so the FAIL is not a reconstructor-only nit; still not a substitute for this file):

- `BaselineScorer` martingale = prior completed `NetRealizedPnl < 0` **and** next `MaxVolumeLots > 1.25×`. Averaging = `trades.Any(t => t.WasAveragedDown)`. Risk **+35 / +20**. `RISK_BLOCKED` only if `risk >= 80` **or** `(Martingale ∧ MaxDrawdown > 0 ∧ NetPnl < 0)`. Averaging alone is risk **20** and can still land **`SHADOW`** when `quality >= 70 && risk < 40`.
- Spec A22 default `MARTINGALE_VOLUME_RATIO = 1.80`; stub uses **1.25** on **closed** trades. Neither is implemented in `TradeReconstructor`.
- `RiskEngine` `BlockMartingale` is a caller-supplied `MartingaleFlag` on increasing actions. `RiskEvaluationRequest` has **no** averaging field.
- `CopyTradingService` sizes dest from `trade.MaxVolumeLots` (the **basket after adds**) and passes `MartingaleFlag = score.Martingale` (inter-trade bit). `WasAveragedDown` is not consulted. Persist forces `AllowFixSend = false` today.

Live census does **not** rescue the filters:

- 8463 source accounts can still run grids on the challenge side. This class reconstructs them as valid completed XAU.
- Achiever scoring can consume those reconstructions. Starwave **deals-done scored 0** means that broker’s left tail is **unscored**, therefore unfiltered by the scorer.
- SHADOW all demo + `destinationRealPnl` **0** + `REAL_COPY` **false** means dest left tail is cut by **not copying**, not by anything in this file.
- FIX **LoggedOn** is session state. Logon without a reconstruction reject is not a left-tail cut.
